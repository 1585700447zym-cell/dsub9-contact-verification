## 环境与验证入口

当前实验使用Windows x64 / Python 3.13，包版本参考[依赖记录](requirements-migration-20261102.txt)。该文件沿用历史名称，不包含定制MuJoCo运行库。建议在隔离环境安装依赖后执行以下数值/合成回放检查：

```powershell
python -m pytest -q tests/test_threeway_online.py tests/test_recurrent_sac.py tests/test_recurrent_replay.py
```

上述检查使用合成回放，包含测试内临时网络优化，不使用科研轨迹训练、不启动物理任务。几何奖励测试另需未附带的历史运行库准入记录，不能在本精简副本中直接运行；不代表全套历史测试均已通过。具体本次验证结果见[发布检查](docs/releases/发布检查_2026-11-17.json)。

**完整任务运行需要额外恢复定制MuJoCo 3.13.0运行库并重新确认路径和准入。** [接触修复说明](deliverables/contact_invalid_t04_20261110/修复与验证.md)及补丁、原始运行库清单已保留；这些清单包含原机路径且受哈希约束，不可仅替换成标准pip版本后声称复现本轮结果。实验脚本也可能依赖未附带的原始回放/权重，不能直接重跑覆盖历史目录。

本版不附最新A/B/C权重，也不提供完整续训包。需要恢复训练时，应单独导出对应检查点、优化器、回放、随机状态和运行库。历史F4000迁移包可从旧提交 `b6105999b846f53f494cbbf9ac69d4f0709d3f7d` 查看，其协议不等同本版。
