# D-sub9：复杂度、观测维数与当前修复优先级

本轮只读审查生产代码与既有档案，另做参考运动的离线数学计算；没有修改控制器/SAC/模型、启动动力学或优化。启动时209条未提交记录继续保留。实时研究状态仍由根目录进度文件维护。

**判断：当前应先修共同搜索边界处置和失败分类，停止扩大观测与学习器。代码确实增加且有重复；本轮故障尚不能归因于SAC，因为新v4正式更新和策略调用均为0。历史120维曾有实际训练后失败，不能把历史失败全部归结为本次问题。**

## 120→137到底改变了什么

120和137都是网络的观测输入宽度，动作一直是XY、roll/pitch四维。2026-10-04接入v4参考搜索、净推进与载荷/旋转风险状态时，新增观测包装器在旧120项之后追加17个标量；不是SAC要求必须使用137维，也不是增加17个控制自由度。

| 新增组 | 标量数 | 用途与必要性判断 |
|---|---:|---|
| 相对驱动参考XYZ | 3 | 显式给出执行器参考位置；可由旧相对位置与参考误差重构 |
| 搜索参考XY＋有效位 | 3 | 显式给出搜索圆内参考；可由旧参考/搜索原点与原点有效位重构 |
| 控制器历史峰值Z＋有效位 | 2 | 控制器记忆；三个已核对档案的活动阶段峰值与旧maximum_advance完全一致，终末/其他路径不能据此全部删除 |
| 搜索净推进剩余量＋有效位 | 2 | 冻结搜索进展基准，具有控制器记忆作用 |
| 旋转风险/高载荷计时，各含有效位 | 4 | 可让无记忆网络看到持续触发时间；仅6ms力历史不能自动恢复所有计时状态 |
| XY重置计数、待参考释放、上次滤波比例 | 3 | 反映会话与动作过滤状态，仍需必要性和消融证据 |
| 合计 | 17 | 没有新增必要性/效果已被证明的结论 |

出处：[v4_observation.py](../../../tools/learning/v4_observation.py:24)、[旧120维构造](../../../tools/learning/observation.py:105)、[初次迁移计划](../../../docs/superpowers/plans/2026-10-04-v4-residual-adapter.md:20)。

本审查在三个真实归档的22,508条观测中核对重构：新增参考组6维可由原字段近似重构，误差为float32舍入量级；活动阶段新增峰值也与旧字段一致。这证明存在冗余，不能证明所有17项在所有状态都冗余，更不能证明137维导致本轮失败。数据、SHA和误差见[audit_metrics.json](audit_metrics.json)。

仅把输入从120改137，actor首层增加4352个参数；actor、双critic及其双target首层合计增加21760个参数。它没有引入新控制算法。为此重建整套维数固定的回放/保存包装，付出了比这次输入变化本身更大的工程成本。

建议：现在保留已核验的137维，停止继续扩展。先修控制问题；随后一次性审核哪些字段进入策略、哪些只留日志，再冻结所有方法相同输入。立即改回120会再次迁移权重和检查点，却不会修复已发生的参考错误。

## 纯SAC、残差SAC和零残差

| 名称 | 实际含义 |
|---|---|
| 纯SAC控制 | SAC直接产生所定义的控制命令，没有B2作为动作叠加基线 |
| 残差SAC | SAC学习小修正，执行命令由B2＋修正再经共同限幅/过滤产生 |
| 零残差 | 修正为0，执行B2；可以完全不调用SAC网络 |

残差RL是传统控制与学习修正叠加的控制结构，不是一种保证成功的SAC变体。[Residual Reinforcement Learning原论文](https://arxiv.org/abs/1812.03201)。SAC是最大熵actor-critic优化算法，优化所给环境中的预期奖励；算法名本身不提供本插接任务的成功证明。[SAC原论文](https://arxiv.org/abs/1801.01290)。

本项目还用了阶段权限、非活动actor/温度屏蔽、物理时间折扣，**并额外用了critic每批240均匀＋16边界重采样、部分终末尾段实际回报替换TD目标**。[边界采样](../../../tools/learning/boundary_targets.py:56)、[v4配置](../../../tools/learning/v4_pilot_contract.py:41)、[更新器](../../../tools/learning/v4_sac.py:156)。

这些共同设置不自动破坏F/S公平比较，但“未经修改的标准SAC”这个名称不准确。边界采样与尾段目标修正属于额外训练处理，应明确记录、必要时消融；没有证据说它们解决了新v4的学习收益问题。控制流程稳定后，建议先取得一个尽量接近标准SAC的完整基准结果，再逐项引入确有需要的学习技巧。不要把输入迁移、控制器修复、critic技巧和actor学习率同时作为收益来源。

## 上次到底是谁失败

纯B2从reset运行的五个已用开发点曾功能5/5；它没有证明在任意残差改变后的状态仍可继续。上轮S也不是从头零残差：它在SEARCH请求100ms保持的随机动作，接近边界后才被过滤归零。F随机预热成功不能归因于学习。

8.756s错误状态的真实参考半径119.979366980μm；下一B2预测120.012974565μm。实际参考没有执行越界，守卫拒绝继续并真实停稳。120μm是内部搜索参考圆，不是论文的80μm附加定位精度，也不是200μm实际搜索位移保护。

更强的检查：用该时刻真实前一XY速度，以及每2ms最多10μm/s的分量速度变化限制，求整个下一速度可达矩形中距离搜索原点最近的点。最小下一半径仍为120.004209959μm，即越界4.21nm。连放宽到整个速度/加速度允许矩形都无解，受阶段/残差限制的动作集合更不可能救回。因此需要在更早的周期避免进入这个状态，或进入合格的停止/恢复；换学习率、增加输入或换SAC网络不能改变这一时刻的可达性。

对75个已归档近边界状态做100ms强制零残差的参考轨迹计算，最大瞬态半径120.029140668μm。说明应客观审核软件参考边界是否设得过于刚性；几十纳米量级的缓冲是值得筛查的候选。但该计算没有接触反馈、实际体位/阶段切换或后续非零动作，**不证明把容差放宽0.1μm就能解决全部问题**。[参考-only重算](reference_counterfactual.json)、[原诊断](../../paper_comparison/v4_learning_pilot_20261006/诊断与下一步.md)。

## 修复顺序与收缩范围

| 优先级 | 应做什么 | 不应同时做什么 | 放行证据 |
|---|---|---|---|
| P0 | 明确共同搜索的软参考边界、提前停止/既有恢复；先用本反例验证，优先小参数/既有状态转移，不再不断叠加短前视层 | 改孔径、定位目标、力保护、网络维数或学习率来掩盖此错误 | 参考/速度/加速度重算通过；相同有限随机预热不再因同一逻辑错误截断，全部失败仍留档 |
| P0 | 区分受控任务失败与接口/仿真/保存故障。已定义、有效停稳且约束保持的失败应带负奖励；当前把全部reference问题拒收/停整轮过于粗糙 | 直接取消错误门、把失败改成功、把现有被拒档案偷偷入池或补跑旧额度 | 原始事实独立分类，正常失败可学习；无效/未停稳/真实约束失守仍按规则拒收/停止 |
| P1 | 冻结一个观测/动作/学习设置，复用现有保存与恢复；先完成真实优化、末次冻结评价、代表恢复 | 再创建一整套v5观测/SAC/回放/检查点包装，或先加新算法技巧 | 有真实批次与完整冻结评价，不以离线检查数量代替效果 |
| P2 | 在稳定入口上消除已确认重复，历史版本保持快照、停止进入活动调用链 | 为减行数删除历史数据、重写旧冻结清单、一次性大重构 | 历史材料保持，活动路径更少、结果一致且变量可解释 |

共同控制器/软边界若改变，需要新共同配置并重评B2/F/S，不能让S单独获得更宽松条件。这里只提出修复优先级，未修改执行合同、参数或代码；原26动态/4000批余量继续关闭。

## 代码是否越写越多

是。当前v4学习相关9文件共914行，另有342行pilot执行器；这只是指定文件组，不是整个项目行数。旧SAC209行、新SAC213行，200行文字完全一致，说明存在可见复制。多个会话继承层、不同版本固定维数的回放/检查点及runner也增加了维护难度。

保留历史、真实停稳、完整检查点、无效隔离是必要工作；并不要求长期复制全部活动实现。此前在单脉冲修复通过后，便推进全套137维学习链，没有先完成持续随机残差下的控制可继续性和失败口径验证，这个实现顺序不够高效。420项离线检查证明指定接口和数值行为，不能用它们宣称学习方法已成功。

后续进度应按“能否完成真实学习与冻结评价、失败是否可解释、收益是否可重复”衡量。先收缩活动路径和实验变量，不再以增加模块、状态维数和检查数作为主要推进方式。本轮没有删历史或增加生产模块。
