# D-sub9 研究问题与证据推进计划表

日期：2026-10-10。当前处于B.2第3项“普通SAC训练与真实任务评价”；本次完成研究顺序和交付要求的规划修订。下表各研究任务尚未完成，文献已有初步线索；本次没有启动新的仿真、训练或模型推理。

当前最优先的是把“问题确实存在且值得解决”核实清楚。先完成定向文献调研与模型适用性核查，再设计并验证合理基线的缺陷；依据缺陷机制选择方法，随后补齐普通SAC对照、候选消融和正式评价。先前“立即准备终末精度奖励候选”的优先顺序由本计划替代，精度奖励是否需要修改由问题与指标依据决定。

## 已有成果与仍缺少的证据

SCOPE20完成2000批更新、训练状态保存和独立恢复；F0/F2000在四个已用开发点的功能成功均4/4。平均任务耗时8.9060→8.6595秒，改善2.77%，未达原10%开发继续条件。SCOPE21离线核对8档案、42171周期，终末80μm/0.5°附加指标为F0 4/4、F2000 0/4；原功能成功标签保持。

F0是零更新随机初始化残差网络的确定性策略，残差并非全零，不能替代纯传统B2。独立恢复一致验证的是运行复现，不等于不同训练种子的性能重复。现有证据仍缺同版本合理基线的完整比较、研究问题的定向文献支持、可重复的基线缺陷、机制验证和冻结后的独立评价。

80μm/0.5°是既有附加开发口径，尚不能当作真实D-sub9产品质量界限。现有刚性九针仿真未标定弹性、电气接触和损伤，载荷只支持模型内比较。原3处逐profile接触覆盖缺口和历次失败均保留。

## 还需补充和修改的安排

研究价值不要求传统方法必然“失败率高”，也不要求新方法所有指标同时领先。明确场景下可重复、幅度有实际意义的效率瓶颈，也可以成为问题；应先确定一个主要改善目标，并把成功、功能质量和保护作为相应约束。当前四点2.77%的耗时变化尚不能支撑稳定优势，更不能通过增加指标数量补出贡献。

| 事项 | 采用的安排 |
|---|---|
| 研究问题与方法顺序 | 先验证问题，再选方法；SAC和阶段/进展约束都是候选，不把算法名称当作问题定义 |
| 公平基线 | 纯B2、普通SAC和简单强对照职责明确；F0只作学习起点诊断；不能用较差参数或较少调参机会制造差距 |
| 成功、精度与载荷 | 功能完成是前提；终末位姿、九针几何余量和力/力矩的用途分别说明。精度阈值须有依据；力保护通过不等于载荷控制已最优，较小净力也不等于针脚无损伤 |
| 指标选择 | 第3项为基线缺陷验证登记指标，第6项为方法实验冻结主张和主次指标；后续调整建立新开发协议，旧主判据及失败不重贴标签；不能在最终测试后挑有利指标 |
| 指标的实际意义 | 精度保留连续位置/姿态误差及其分布，再说明阈值与插入几何或任务质量的关系；成功率与时间同时报告，失败惩罚/超时口径预先固定，不能只比较成功回合均值。载荷是否列为核心指标取决于其与问题的联系和模型可信度 |
| 问题可解性 | 判断任务需要的信息是否可获得、动作是否能有效改变相关状态；相同初始观测不证明整轮不可学，使用奖励真值也不等于策略已经获得孔位信息 |
| 实验单位与重复性 | 控制周期不当作独立性能样本，检查点恢复重复不增加成功率样本；固定确定性配置的重复主要查运行一致性，跨训练种子/未用工况才支撑更广泛的效果判断 |
| 公共改动与方法贡献 | 共同裁判、保护、奖励或模型修复统一用于相关方法；如果把某项改动本身作为贡献，安排独立对照解释其作用 |
| 模型适用性 | 在当前可信几何、姿态、接触与停止范围内设计首轮；扩大范围先补必要资格，原3处覆盖缺口不因计划修改自动消失 |
| 预算与停止 | 每个执行包列清新回合、更新、恢复验证和实际墙钟上限；复用档案说明版本一致性，不重开旧预算；没有机制或收益信号时按表中条件结束或转向 |

## 下一项交付

下一项只完成第1、2项的联合离线交付，名称为“定向文献与场景适用性核查”。本轮已发现的文献作为检索种子，不能冒充系统调研已完成。首批围绕8～12篇直接相关原始研究核对，数量只是控制阅读范围；以覆盖合理传统方法、近期学习/约束方法、关键反例和工程条件为完成依据，必要时只补缺失的关键原文。

交付内容为：

1. 可回溯到原文表格/段落的文献对照表，并注明全文或摘要可得性、检索日期、术语、引用追踪和适用限制。
2. 2～3个候选问题卡片，分别写明场景、合理基线、具体不足、可能机制、现有方法、尚未解决部分及反证。
3. 与当前模型、观测、动作、已有档案和限定资格逐项对应的适用性表；明确哪些问题现在无法验证。
4. 一个优先问题建议及排除其他候选的理由；若没有足够依据，明确结论为“尚未选定”，列出最小补充证据，不转入新训练。
5. 第3项场景/基线验证的简要提纲。初始误差范围、强对照和样本数量以本次核查证据确定；尚不执行新的物理或学习计算。
