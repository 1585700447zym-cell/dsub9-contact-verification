## 新获得的能力

- 独立候选环境：实际四元数相对起点转角检查，同一物理子步完整接触/运动/数值事实采集。
- 有限运动失败进入物理停止，数值无效单独锁存；STOPPING新故障仍记录，不重启物理停止时钟或延长既有任务观察窗口。
- 候选B2会话消费新事实；安全尾段故障可否决原任务窗口内成功，不获得新的成功机会。
- 无效动作即使在屏蔽阶段也关闭回合；拒绝reset不暴露旧回合停止统计；故障后不得恢复。
- 独立动态探针和完整B2回归入口，保留原始轨迹、事件、每物理子步停止样本、运行输入和源快照。

原兼容层、冻结动力学/控制器、历史七工况、合同v2和旧清单没有按新规则重写。新实现位于`tools/learning/guarded_environment.py`、`guarded_session.py`，不将候选姿态参数加入原动力学默认值。

## 2.5°候选的正确解释

四个正反向roll/pitch自由接近试验均触发并停稳，但最大实际转角约**2.513404°**。2.5°是检测/停止触发角，不是硬性姿态上限。自由接近试验Z=-5mm、接触开启，不能替代Z=-4mm训练起点的接触探索检查。

一个接触roll试验触发0.025N力守卫并停止合格。负pitch试验峰值约0.024901N，没有达到预定过载触发目标；它按4s试验预算停止合格。没有降低阈值或延长该已登记试验去追认通过。

几何尺度、初始姿态与相对姿态区别、历史包络及剩余证据见[候选参数记录](姿态候选参数记录.md)。当前证据不支持把2.5°冻结为整个训练分布的可信范围。
