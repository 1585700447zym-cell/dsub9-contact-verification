# B1-07｜姿态参数与模型适用范围冻结审查

2026-09-24。**本轮完成审查及有限静态补验，结论是不冻结2.5°、不开放模型范围或训练准入。** 这不是架构推倒重做，也没有修改现有保护、奖励、模型或控制器。当前状态仍以[进度跟踪](../../../项目进度跟踪.md)为准，查找与汇报继续使用[交付总览](../../../项目交付总览.md)和[9月滚动月报](../../monthly_progress/2026-09/月报素材_2026-09.md)。

## 核心判断

目前2.5°只能称为相对回合起点的**候选检测/停止触发角**，不能称为无接触安全角、最大实际角或单独决定模型有效性的范围。角度、初始姿态、当前位置/深度、接触/穿透及停止过程必须合起来判读；现有代码本来就有这些独立守卫，本轮不新增或放宽规则。

| 冻结要求 | 已有证据 | 本轮判断 |
|---|---|---|
| 角度定义和处置 | 真实四元数相对起点最短SO(3)角，每0.2ms检查，锁存后停止且禁止恢复 | 定义明确；不是绝对孔轴倾角，不是欧拉角累计 |
| 基线包络 | 旧14个B1/B2回合2ms采样：B1约2.121388°、B2约1.657809°；新共同守卫B2七工况逐字段一致，子步最大1.657809402° | 支持既有B2兼容；B1只有旧采样包络，不冒充已完成同守卫B1子步复验 |
| 候选边界处置 | 4例Z=−5mm无接触自由接近在2.5°触发，最大约2.513404°且停稳 | 支持这4例边界停止，不提供接触状态下的超调上界 |

| 候选附近几何检出 | 本轮243规定静态姿态检查通过，241点有明确见证和接触，1969个对应针孔正见证无漏检 | 补齐指定静态取样，不认证连续域、D形外壳、力准确性或动态可达性 |

**“静态检查通过”不等于“动态守卫通过”。** 240个边界网格点的最大碰撞穿透都超过原30μm停止值，156点超过原80μm无效值；若将这些几何状态送入动态守卫，相应穿透条件会被拒绝。最大约174.436μm；本次静态合力最大却只有约0.0144091N，低于0.025N力阈值，说明不能只看合力决定是否合格。这里没有新物理回合，不能把强制交叠称为闭环必然到达的状态，或据此宣称引擎数值失稳。原阈值一律不变。

2.5°时4mm轴向尺度的横向偏移约174.64μm，已大于75μm名义径向间隙；该尺度分析与静态诊断一致，但不是完整多针/外壳碰撞证明。256段主孔的理想多边形径向近似误差约0.0433μm，亦不是载荷标定或引擎精度保证。

## 处置与下一项

1. 保留2.5°为候选，不增大、不缩小、不冻结；80μm无效穿透和30μm停止判据原样保留。`parameter_frozen=false`、`model_scope_qualified=false`、`training_admitted=false`。
2. 下一项只补工程初始角0范围的**有界时变残差动态边界检查**：运行前明确少量开发工况、动作时序、2.5°候选、原任务/停止预算及统计口径。最多8个预登记完整回合，不搜索参数凑触发；保留全部尝试。
3. 接触保护若先触发，应如实记作该分支的停止证据；不能关闭接触、绕过穿透守卫、抬高动作幅度或任务预算来强迫命中2.5°。若仍无接触态角度边界证据，保持缺口并报告，不将8回合耗尽当冻结通过。
4. 定向检查结束后审查触发前后姿态、接触/穿透、全部有效性事件和实际停止，明确哪些条件下的失败可学习；缺少模型适用依据时仍隔离。若证据要求改保护、动作、奖励或研究范围，先与用户沟通。

正式准入指纹绑定、完整学习/训练器恢复、配置及独立成本仍在后续。本轮没有SAC更新、未使用独立测试集，也没有加入机器人或夹爪。
