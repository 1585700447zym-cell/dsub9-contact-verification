## 原局部状态到会话的映射

| 状态 | reset值 | 修改位置与职责 |
|---|---|---|
| reason / stop_time | None / None | `_finish`记录任务决定；`_post_task_cycle`按原时序确定成功或未稳定；prepare处理原预算/恢复前置分支 |
| hold_start | None | `_post_task_cycle`维护任务窗口内成功连续保持；尾段不再更新 |
| recovery_state / wait_start | None / None | prepare处理等待、请求、恢复，post处理回撤停止进入等待；`_finish`清除恢复状态 |
| guard_latched | False | `_post_task_cycle`只锁存第一次旧B2累计载荷违规；不是v3子步多事实守卫 |
| task_finished / task_end_time | False / None | post结束原任务窗口，advance记录时刻；后续只续安全尾段 |
| done | False | advance在原终止或最终STOPPING起点2s后结束；不代表单独停止审核已通过 |
| cycle_id / cache | 0 / None | reset准备首周期，advance消费、加一、准备下一周期；observe仅复制缓存 |
| controller历史/导纳/阶段 | 新控制器实例 | 仅prepare在原应更新的位置调用command；快照读取不调用command |
| 周期峰值/停止样本 | 全零/空列表 | reset清空，begin_cycle清周期峰值，物理采样回调更新 |

此阶段通过的是旧兼容行为；动作/奖励/经验模块尚未连入会话，新增守卫、观测与Gym仍待实现。
