## 姿态参数：等待候选验证决定

[姿态包络分析](orientation_envelope.json)读取14个冻结开发回合（含停止尾段）。2ms记录中，B1相对初始姿态最大约2.121388°，B2约1.657809°。这不是物理子步姿态的完整上界，更不是残差探索的可信边界。

建议仅把2.5°登记为**待验证候选**，用户确认后做几何可信范围检查、边界内/外的动态停止，以及同共同版本对照；不能现在设为已验证默认值。以4.5mm轴向尺度举例，2.5°对应约196.5μm横向变化，超过75μm名义径向间隙；因此“比基线转角稍大”本身不足以证明安全。这个简单尺度估算也不是完整多针碰撞边界。
