## 判定口径

初始化项要求真实复位、数值及观测有效；不要求“物理停稳”，因为没有执行运动。动态项要求完成原回合及停止审核、数值/观测/权限有效；非零项还要求记录到命令限制层面的残差有效改变量。有限保护失败可以满足本次预检，不会计作装配成功。

所有ID、工况和动作必须与预登记逐项匹配，少项、重复、错配、异常、未停稳或源文件变化都令样点检查失败。每个尝试独立保存gzip原始记录，包含每控制周期物理轨迹、动作限制日志、奖励、接触峰值、事件及停止子步样本。`attempts_so_far.json`仅是运行中进度，最终以`assessment.json`及完整原始记录为准。

13000控制周期（26s仿真时间）仅为诊断看门狗：触发即失败，随后尽力停止，不能当正常任务超时或成功。它不能中断卡在原生引擎内部的调用，不是墙钟超时。数据检查失败在结论中持续锁存，但后续健康周期可以继续完成停止收尾；不会因收尾完成把失败改写为通过。

`sample_checks_passed`只表示已登记样点的上述检查是否通过；`domain_qualified=false`、`training_admitted=false`、`valid_for_learning=false`始终保留。没有经验入池、优化器更新、训练权重或独立测试集使用。
