## 姿态边界证据究竟补到了什么

四角0在11.4944s的物理子步触发`ROTATION_LIMIT`，当时相对起点角为2.500001596°，**该子步接触数为0**。全回合最大角2.503932491°，相对候选值的本例超调约0.003932491°；原停止审核通过。

其后停止尾段有2个2ms采样端点仍有接触，其中最大角2.502420275°，停止尾段周期力峰值0.000495009N。因此取得的是**经历接触 → 角度触发 → 停止尾段再接触 → 有效停稳**的有限联合证据，不是“在有接触的那个子步触发角度守卫”。精确触发子步有接触的回合数仍为0。

停止尾段接触端点和触发前后100ms的6个接触端点，是对保留原始记录的事后描述，不是新增通过门。2ms端点角度不能冒充全部接触子步最大角度；本例超调不是普遍上界。没有因缺少某种瞬间条件而扩大预算或寻找另一组参数凑结果。

B1-07的156个规定静态姿态超无效穿透，与本次8回合最大穿透约7.34μm并不矛盾：规定强制交叠与实际闭环轨迹不是同一组状态。两者共同要求按姿态、位置、深度、接触/穿透和停止审核界定数据有效性，不能把角度单项当模型安全证明。
