# 2026年9月月报素材：从零残差封装进入可交互接口

## 本轮获得的能力

在保留冻结物理模型和B2基线的前提下，建立120维白名单策略输入、四维非零残差交互、Gym风格单步接口，以及回合结束后统一审核的数据通路。具备接口调试与后续学习集成的基础，但尚未运行SAC或产出训练权重。

新增观测包含实际运动、仿真接触反馈及可知的控制器状态；孔中心真值、初始误差标签和穿透量不进入策略。首次非零动作通过共同限制后确实影响仿真运动，不能据此宣称已学会接触纠偏。

## 关键可靠性工作

- 外部截断在截止点保存下一状态；独立停止审核不覆盖该状态，也不虚构成功/超时奖励。
- 非法动作和后期数值故障隔离整回合；非法初始化也计入尝试记录，不能通过重采样隐藏问题。
- 工程化回撤验证中，持续非零请求在回撤全过程被屏蔽；达到真实回撤条件、恢复搜索后重新放行。
- 独立审查促成五类修正：异常后关闭会话、失败初始化不漏计、源时间拒绝NaN/Inf、切换时实时参考、固定字段形状。修正后的接口专项49/49通过。

完整学习接口测试143/143通过，旧非编译套件429项通过且跳过的1项在正确隔离运行时补验通过；23项旧插件编译未重跑。七工况双重精确回归的最终结果、耗时和源指纹见本目录README及机器报告；不以接口测试代替全阶段训练准入。

七个开发工况最终7/7与原始及同守卫版本归档精确一致：覆盖36708任务周期、4640尾段周期和413480物理子步。原3/7成功与4/7正常失败保留，说明新增接口未改变这些零残差回合，而不是学习带来提升。809项输入及源快照核验一致，另保留21个测试快照。

## 负结果与限制

实际导入PyTorch失败，说明“安装版本存在”不等于“训练环境可用”。当前NumPy损失检查只能验证数值语义，不能替代自动微分、优化器、SAC运行、保存加载和训练耗时。原环境保持未改，后续需独立依赖环境。

所有候选经验仍不可学习，2.5°姿态范围未冻结；没有独立测试评价、学习收益、创新有效性或实物适用性结论。本轮不引入完整机器人/夹爪。历史七工况仍为开发资料，不能用作未见测试集。
