# 白名单观测与调用约定

版本 `residual_whitelist_v1`，float32，120维，固定字段顺序；原始SI值独立保留，归一化后裁剪至[-10,10]。守卫不使用裁剪值。四个控制采样间距2ms、首尾跨度6ms；不声称替代0.4s受阻历史或构成严格马尔可夫状态。

## 字段表

来源分为相对运动测量、仿真接触反馈、已知控制器/会话状态。仿真接触反馈未标定为真实FT传感器。以下所有策略字段均可在`policy_raw`中找到对应未归一化值；独立求解器真值只在`privileged_evaluation`或守卫/奖励中使用。

| 字段 | 宽度 | 原始单位/归一化尺度 | 来源/有效性 |
|---|---:|---|---|
| wrench_history_M | 24 | 每采样F/0.025N、T/0.0005Nm | M点六维仿真接触反馈，最新在前，reset重复首样本4次 |
| relative_position_m | 3 | m/0.004 | 相对回合起点运动，无绝对目标 |
| relative_rotation_world_rad | 3 | rad/0.08 | `q_current * inverse(q_initial)`最短旋转向量，世界轴 |
| velocity_world | 6 | 平移/0.001m/s，旋转/0.03rad/s | 运动反馈 |
| maximum_advance_m | 1 | m/0.004 | 已观察相对Z最大正推进；奖励另按目标行程封顶 |

| search_origin_m、search_origin_valid | 3+1 | m/0.004；0/1 | B2已相对起点表达的搜索原点；未定义填0 |

## 时序与缓存

`reset`重建控制器、历史、奖励和动作记录。`prepare_cycle`首次完成当前周期前置处理及基线更新；重复prepare/observe只读。advance积分后生成下一周期缓存。异常改变同周期阶段时允许刷新状态标记，但不再插入一次力历史。

## 使用示例（候选验证，不是训练）

```python
from pathlib import Path
from tools.learning.runtime import verify_runtime
verify_runtime(Path('tmp/mujoco_3_13_probe'))  # 先于动力学模块导入
from math import radians
from tools.learning.guarded_environment import GuardCandidateConfig, LearningEnvironment
from tools.learning.residual_session import ResidualSession
from tools.learning.env import ResidualEnv
from tools.validation.run_b1_baseline import cases
physics = LearningEnvironment(guard_config=GuardCandidateConfig(
    max_rotation_from_start_rad=radians(2.5), initial_roll_pitch_limit_rad=radians(1.5)))
env = ResidualEnv(session=ResidualSession(environment=physics), case=cases()[0])
observation, info = env.reset(seed=2026092201)
observation, reward, terminated, truncated, info = env.step([0, 0, 0, 0])
# 若确需提前终止本次采样：下一步后保存cut状态，并独立完成停止审核。
observation, reward, terminated, truncated, info = env.truncate_after_step([0, 0, 0, 0])
env.close()
```

- 普通采样批次边界不调用截断；完整任务在停止审核后返回terminated。
- 不能套通用TimeLimit/自动复位收集器来绕过整回合审核。活动回合reset/close拒绝，须先完成或显式截断。这里是受约束的Gym风格适配，不宣称可直接交给SB3.learn。
- 真实截断返回截止点next_observation及对应Δt、折扣和奖励；尾段不替换该状态、不补任务终末奖励、不加入截止经验。
- 四维归一化经验动作与六维命令分开存；无权限时经验动作规范为零，但NaN/Inf仍为无效输入。
- 数值/接口错误隔离先前全部转移，保留失败尝试与非有限标签；不自动重采样。当前候选的所有回合都拒绝发布，`sink`为空。
- `attempts`是内存归档，长时间运行需后续采集器持久化/容量管理；当前不是无界长训收集器。
- `learning_masks`只是NumPy确定性损失/目标的数值参照，未连接优化器；不能替代PyTorch梯度与保存加载验证。
