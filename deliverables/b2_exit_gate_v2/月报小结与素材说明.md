# 月报增量素材：B2-5.1

建议标题：**完成回撤恢复策略的定点对照，识别搜索与推进切换的性能退化。**

可直接讲述：

“在已有接触模型和安全阈值不变的条件下，我们针对恢复搜索的退出判据做了两工况对照。更严格的判据避免了过早判断搜索完成，但没有提高装配表现，原本能够达到目标深度的 X 偏差工况反而退步。因此保留旧基线，下一步集中分析横向搜索与轴向推进的切换，而不是直接扩大训练。”

这里的“安全阈值”指仿真中的开发保护参数，未完成实物标定。对照仅是两个固定开发工况，不能表述为统计成功率。

## 可报告的进展

1. 保留原始模型、旧基线与失败记录，仅改变一个状态判据，形成可追溯的对照链。
2. 完成两次新动力学试验；新旧分叉前轨迹逐样本一致，限制了混杂因素。
3. 新版峰值力分别约 24.477/24.501 mN，最大穿透约 15.147/16.502 μm；均低于原保护阈值。失败由搜索预算耗尽触发，不是力保护触发，也不是 20 s 总时限耗尽。
4. 得到明确的否定结果：严格退出条件本身不足以改善插入；现阶段不宣称装配已经成功，也不把新版作为训练基线。
