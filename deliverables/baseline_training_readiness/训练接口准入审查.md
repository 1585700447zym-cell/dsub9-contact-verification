# 训练接口准入审查（结论：停止可靠性阻塞）

本文件区分已有实现与下一能力才实现的封装。当前训练准入不通过：原 B2 Y 在停止后 2 s 内未持续停稳。

## 已有链路及边界

`工况 → 控制器观测 → B1/B2 速度命令 → 笛卡尔驱动/独立保护 → MuJoCo 物理子步 → 同时刻观测 → 完成判定与日志`。

| 环节 | 已有实现 | 准入审查 |
|---|---|---|
| 物理模型 | 256 段凸碰撞、MPR，0.2 ms 物理步、2 ms 控制周期 | 当前时间步复验另行记录；128/256 敏感性仍是限制 |
| 命令 | 世界/任务轴表达的 M 点六维速度；导纳修正 XY、roll/pitch | 四维 SAC 残差尚未接入；不得写成六维学习策略 |
| 实际运动 | 每物理步施加有限驱动力，再积分；只有 reset 直接设位姿 | 不以动画插值代替物理轨迹 |
| 反馈 | `mj_step` 后 `mj_forward`，再读取同一时刻位姿、速度和接触力 | 当前是仿真接触合力，不是六维传感器完整读数；未经设备标定 |
| 守卫 | 每物理步检查有限数、穿透、载荷、速度/行程；总命令限速/限加速度 | 原始物理步峰值用于判断，不仅检查 2 ms 日志 |
| 停止 | 撤销运动命令、保持参考；不瞬间将速度清零 | 撤销命令≠物理静止。旧 B2 Y 最终速度 13.365 μm/s，未满足 10 μm/s 静止条件 |
| 回撤 | 稳定且低载荷才允许，一次、有限距离/速度/时间；B2 保护触发后不继续恢复 | 旧十四回合的恢复顺序和保护锁存由既有统计器复核 |
| 成功 | Z/XY/姿态、线/角速度、连续保持 0.1 s、全程峰值约束一起判断 | 原十四回合完整成功均为同轴；深度到位不替代成功 |
| 无效仿真 | 非有限数、MuJoCo 警告、严重穿透等独立原因码 | SAC 经验池隔离和无效回合统计尚待训练封装实现 |

## 后续接口必须保留的约束

- 策略可用：六维力/力矩、可测的相对起点运动、基线命令、阶段、动作历史、剩余预算。策略不可直接用真实孔中心误差、逐针孔身份和穿透真值；这些单列为奖励/评价特权信息。
- 动作是四维归一化速度残差，叠加在冻结基线上后，由同一守卫约束总命令。零残差须复现冻结基线。
- reset 同时清空控制器、历史窗口、滤波与恢复次数；不能只重置 MuJoCo 状态。
- 保护、无效仿真与成功冲突时不让成功覆盖前者。终止原因、物理停止状态、是否允许学习是不同字段。
- 任务预算结束与外部采样截断必须分别定义，不能随意混用 terminated/truncated。观察与奖励时序需由实际适配器测试。
- 旧七工况属于开发集，不能作为独立测试集。训练/验证/测试分布和种子需在学习前单独冻结；当前未生成或冒称已经冻结。
