# 独立版本可行性检查

官方发布页列有 MuJoCo 3.13.0；本机正式 Python 环境仍为 3.9.0。本轮仅将 3.13.0 官方 PyPI wheel 放在项目 tmp/mujoco_3_13_probe 目录，以独立进程优先导入该目录，不安装或升级现有环境，也不重建 SDF 插件。

固定三个 minimal_v2 XML，分别用原 3.9.0 与独立 3.13.0 各计算一次 keyframe 0 的静态接触。不得改容差、几何或位姿以追求通过。记录引擎版本和导入路径、XML 哈希、编译几何及接触。若新版仍复现异常，则否决“直接升级能解决本例”的路径；若不再复现，也只表示值得进一步完整回归，不能直接升级正式环境。
