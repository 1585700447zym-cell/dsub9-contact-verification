# Dsub9 最小闭环接口协议

版本 0.1 设计稿　2026年9月14日

本协议约定后续简化笛卡尔动态环境、B1/B2和四维残差SAC共用的接口。它是实现依据，不代表环境或控制器已经实现。当前接触覆盖审计不通过，因此可先做自由空间运动与坐标验证；接触控制、训练和正式参数冻结须在覆盖修复和动态验证后进行。

## 坐标与测量

采用米、秒、弧度、牛顿和牛顿米。任务坐标T固定于母头插合原点，+Z为插入方向，+Y指向五孔行。初版让T与世界坐标轴对齐，但所有日志仍显式标出坐标系。

M为公头插合坐标，G为建议夹持坐标，S为模拟力觉测量坐标。M到G的初始定义为位置(0,0,-0.0145)m、无相对旋转。G来自CAD建议，未经真实夹持标定；S须独立定义，不能默认等于G或机器人法兰。

reset输入先给出公头插合原点的位置和姿态，再由固定变换求出夹持点目标。位置与倾角偏差描述实际公头姿态，不描述绕夹持点施加的增量旋转。本轮夹持点对照已表明，这两种初始化会产生不同的针尖位置。

测量记录必须包含：源类型、参考点、表达坐标系、时间戳和是否去除重力/惯性分量。首版允许使用模型接触合力，但应标为 `simulation_contact_wrench`；它不等于实际串联六维传感器完整读数。

同一表达坐标下，将关于M的力矩换算到G：

`tau_G = tau_M + (p_M - p_G) × F`。

若坐标轴也变化，先统一力、力矩和位移的表达坐标，再使用上述关系。用已知方向的单一载荷验证符号和力臂。滤波器在reset时清空；记录原始与滤波后数据及滤波延迟。独立保护至少监视有限数与原始载荷峰值，不能只监视平滑后的观测。

## 生命周期

| 接口 | 输入 | 输出与约束 |
|---|---|---|
| reset | seed、case_id、模型/控制器配置、公头初始姿态 | observation、info；检查初始重叠与有限数，重置控制器/滤波/恢复计数 |
| observe | 当前仿真状态 | 一致时间戳的观测，不改变状态 |
| step | 四维归一化残差，B1/B2运行时为全零 | observation、reward、terminated、truncated、info；推进一个控制周期 |
| stop | 原因码 | 撤销推进命令，执行受限减速或保持；记录实际响应，不假定立即物理静止 |
| request_recovery | 可恢复原因、当前计数 | 由独立守卫准入，先停再回撤；不直接重置位置 |
| close | 无 | 释放资源，不改写本回合数据 |

reset验证失败返回明确错误及无效初始化记录，不悄悄多次抽样直到得到容易成功的初始状态。回合终止后拒绝继续step，必须显式reset。

## 观测

最小策略观测为：六维F/T短时窗特征、相对起点的可测位姿/速度、插入方向累计推进量、当前基线六维命令、阶段、上一周期实际动作及剩余时间/重试预算。

公头与真实孔中心的精确误差、接触点真值、针孔配对和几何穿透不默认进入策略观测。仿真可用这些量做初始有效性检查、奖励、成功判定及评价，记录为 `privileged_evaluation`，与策略输入分开。

姿态内部使用单位四元数wxyz；对外初始误差使用 `R=Ry(pitch)Rx(roll)`，先绕X再绕Y。姿态增量采用旋转积分，不能长期简单累加欧拉角。初版偏航由固定参考与基线约束，SAC不控制偏航。

## 动作的明确含义

首版选择速度残差：`a=[ax,ay,aroll,apitch]`，各分量在[-1,1]。

`residual=[sx*ax, sy*ay, 0, swx*aroll, swy*apitch, 0]`。

这是在任务坐标T中、作用于公头插合参考点M的平移/角速度修正。sx、sy单位m/s，swx、swy单位rad/s；不能将每周期位移和速度混用。控制周期内参考位移由速度乘周期得到。若执行器定义在G，必须根据刚体速度关系转换参考点。

执行顺序：基线命令 → 固定边界或阶段权限约束后的残差 → 两者相加 → 独立守卫限制总命令 → 底层受限驱动 → 物理步进。守卫必须限制最终动作，不只限制残差；记录每次限幅原因及限幅前后数值。

普通SAC使用固定残差边界。候选方法调整平移与转动的允许幅度和变化率，最大动作预算、观测、B2和守卫在公平对照中保持一致。

动作边界、总速度/加速度及力矩限制在动态开发配置中显式赋值。当前不凭未标定的V1峰值制造“设备安全参数”。任何必需限制缺失，启动器应拒绝进入接触控制模式，允许单独运行无接触的接口检查。

## 时间与阶段

建议初始实验设置：物理步长0.0002s，控制周期0.002s，每控制周期10个物理步；仅为待验证的开发起点，不是已通过的推荐控制频率。后续比较0.0001/0.0002/0.0004s时保持控制周期0.002s，分别20/10/5子步。

每个物理子步都检查数值异常、严重几何重叠和原始载荷，防止仅在控制周期末检查而漏掉峰值。物理步、控制步、无界面每秒仿真步和每秒控制步分别计数。

阶段枚举：APPROACH、CONTACT、INSERT、HOLD、STOPPING、RETRACT、TERMINAL。阶段由可观测短窗信息和规则切换，设置迟滞及最短驻留；阈值与窗口在开发配置版本中冻结。恢复过程计入总时间、载荷、重试次数及动作预算。

## 成功与各类终止

| 原因码 | 判据设计 | API映射 |
|---|---|---|
| SUCCESS | 公母插合位姿在容差内、进展达到几何目标、低速保持指定时间，并无保护冲突 | terminated=true |
| OVERLOAD | 原始力或力矩越过仿真保护限值 | terminated=true；可恢复模式在终止前另走恢复流程 |
| NO_PROGRESS | 指定观察窗内推进不足、尝试预算耗尽 | terminated=true |
| OUT_OF_BOUNDS | 位移/姿态超出冻结工作范围 | terminated=true |
| TIME_LIMIT | 达到回合总时间预算 | truncated=true |
| INVALID_SIMULATION | 非有限状态、严重非物理穿透、明显接触漏检等 | terminated=true；valid_for_learning=false |
| USER_ABORT | 人工停止 | truncated=true；单列统计 |

terminated与truncated不同时为真。多个事件同时发生时全部写入 `events`，主原因优先级为INVALID_SIMULATION > OVERLOAD > OUT_OF_BOUNDS > SUCCESS > NO_PROGRESS > TIME_LIMIT。对成功施加低载荷/低速保持要求，避免最后一步刚超载却被成功覆盖。

TIME_LIMIT若只是外部采样截断，训练器采用适当的价值bootstrap；若时间预算本身定义任务失败，应显式在任务配置中改为终止并提供剩余时间观测。禁止两种含义共用而不记录。

当前4mm源于V1起点与名义插合目标的差值；改变reset起点后必须从几何目标重新计算，不能始终硬编码“移动4mm即成功”。同轴自由通过可用于运动检查，不能作为导纳有效的唯一证据。实物是否电连接/锁止，本仿真不做结论。

无效仿真不与正常装配失败混合计算唯一一个成功率。报告全部尝试数、无效数、有效回合成功率和全部尝试的成功占比；禁止仅删除无效回合来美化结果。默认不将无效仿真transition加入SAC经验池，单独保存调试信息。

## 停止与条件恢复

守卫触发不等于力永不越限。记录触发时载荷、之后的载荷峰值、实际停止时间及是否继续穿透。数值异常时终止并保存最后有限状态，不盲目回撤。

可恢复事件先停止推进；只有状态有限、载荷在恢复允许范围、回撤方向和剩余距离可用时才准入回撤。回撤速度、距离、次数和总时间均有限。B1先实现停止；B2的搜索恢复在相同保护体系下增加。

## 单步日志字段

每条日志包含：schema_version、run_id、episode_id、model/config/controller版本与哈希、seed、case_id、仿真时间/控制序号、原始F/T、滤波F/T、位姿速度、基线命令、策略原始输出、约束后残差、总命令、守卫后命令、实际动作、阶段、全部事件、主终止原因、是否有效、评价真值。

同时记录GPU/CPU环境、物理步长、控制周期、驱动质量惯量、夹持/传感器变换。真实值未知时使用明确标注的仿真假设；不把本机未测参数写成CR5或所购设备规格。

## 后续自动验收清单

- 零残差与基线在相同种子下产生相同命令；四维残差可分别改变对应方向。
- 已知单轴力及力臂产生正确F/T变换；reset清空滤波器和控制器状态。
- 相同实际初始公头姿态在不同参考点表达下得到相同几何，而不是重新绕新参考点旋转。
- 总命令超限时被守卫限制；独立触发每种终止，验证同时事件的优先级。
- 无效初始化不进入正常episode；非有限动作或观测被拒绝/中止。
- 成功需满足完整几何与保持条件，separated不能被判成功。
- 动态运动、接触反力影响运动、停止、回撤、不同物理步长一致性分别验证。

这些是待实现环境的验收要求；本次已执行的是诊断工具测试，不能将本清单写成已通过。
