# 30秒共同方案下的450/900搜索速度对照

代码与配置已修改，本阶段只做纯逻辑及合成归档验证，没有运行新的仿真、推理或训练。两组均采用“取消次数硬终止＋旋转软风险仅预警”的共同新方案。旧450历史记录不能当作本次新450对照组。

| 项目 | 新450组 | 新900组 |
|---|---|---|
| 全阶段任务时间 | 30秒绝对时间 | 同左 |
| 搜索/回撤累计次数终止 | 取消，真实计数继续记录 | 同左 |
| 带载旋转软风险 | 原阈值及50ms持续条件，仅预警 | 同左 |
| 螺旋标称速度 | 450 μm/s | 900 μm/s |
| SEARCH XY分量与合成夹限 | ±450 μm/s | ±900 μm/s |
| 被动yaw、冻结策略、噪声保持 | 开启、F4000、50ms | 同左 |

真实重试过程仍包括卸载、搜索、物理停止、回撤和恢复准入；每一段都计入原回合时间。恢复不清事件、最大载荷、保护事实或计数。按完整已恢复事件段及当前恢复段核验，防止重复使用同一回撤。实际距离、停稳、载荷、有效仿真和硬保护仍是恢复条件；卸载超时、回撤未完成等原有保护性失败处理保留。普通轴向卡滞仍可触发卸载/搜索。

软风险持续时只追加一次`LOADED_ROTATION_WARNING`，不强制进入UNLOAD、不重置阶段计时，也不取消策略权限；条件解除后再触发可再记一次。普通父控制链每周期仍只执行一次。风险使用相对初始姿态的总转角，不改其计算含义。

驱动1 mm/s、5 mm/s²平移加速度、角速度/角加速度、INSERT XY夹限、Z插入/回撤速度、400μm搜索盘、120μm参考超前、导纳参数、SAC尺度、奖励、目标几何、10nm裁判和100ms成功保持均保持。900是标称命令，实际跟踪仍受现有加速度等约束，不能预先断言节时或提高成功率。

## 入口与配置

新入口为`tools.learning.time_budget_trial`，明确提供`environment_class()`、`session_class(450/900)`、`collect_episode()`和`audit_archive(..., search_speed_um_s=450/900)`。原入口默认保留原次数/风险处理，历史批次runner与合同不改写。

在工作目录执行以下命令只打印两组配置，不创建环境或执行回合：

```powershell
.\tmp\learning_cpu_20260924\Scripts\python.exe -m tools.learning.time_budget_trial
```

两组已保存于[search_450.json](search_450.json)、[search_900.json](search_900.json)和[comparison.json](comparison.json)。新环境与新session必须配套使用。后续实际批次应使用原冻结权重加载参数和50ms `FrozenHeldPolicy`，在新采集入口中保存轨迹；独立来源审核仍使用同种子 `HeldSourceReplay`，同时核验被动yaw递推、实际参考边界和停稳。旧`consistent_sac.collect_episode`及历史runner刻意拒绝新合同，不能直接复用旧登记启动。

140维布局和动作尺度保持；两个原“剩余次数”槽在新观测版本中明确改成30秒内的次数许可（1或0），其schema来源标为`time_only_retry_permission`。不伪报旧2/1次额度、不使用无穷值、不重置真实计数。`controller_config.max_searches=2`保留为旧dataclass兼容字段，新入口明确登记`effective_max_searches/effective_max_recoveries=null`，由新许可钩子取消其实际作用。F4000只保证维度兼容；新输入分布及恢复状态的策略表现须另行验证。

新完整归档审核通过显式分支复用原来源、物理参考、奖励、成功保持和停止核验，并验证新预算语义、登记组的SEARCH上限、G1尺度及中途旧风险/次数硬终止事件的缺席。审核默认旧分支不变；不将新归档冒称旧训练合同下的数据，也不发布到训练回放。
