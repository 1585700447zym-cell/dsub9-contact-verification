## 当前使用入口与限制

`execution.log` 留完整执行输出；`run/ledger.json` 留全部动态启动；训练区的 `update_budget.json` 区分 attempted/completed/failed_or_invalidated。每个阶段原回合压缩档案与指标分别保存。检查点中含完整原始回放、优化器、温度、随机状态、轮次和额度。

本包是单种子、四个开发点及四个极小独立幅值点。恢复重放不增加独立样本数；正结果不证明统计优势，负结果不证明SAC普遍无效。证据完整后可做限定B.2收口；硬停止或独立评价缺失则保持未完成。
