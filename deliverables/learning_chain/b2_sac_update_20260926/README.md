## 核验所得与限制

- 无权限转移仍用于critic；actor/温度只用有权限行，全屏蔽时不执行其Adam step。下一状态无权限时规范为零动作且无熵收益；真实截断保留bootstrap，任务终止不bootstrap。
- 每批更新异常时回滚网络、优化器、温度、随机状态和计数并锁定；这是进程内数值事务，不是断电/崩溃恢复或完整训练检查点。
- [机器判定](assessment.json)从原始转移重建经验池及独立随机流，重放16批更新与8次策略动作，结果精确一致；[参数摘要](network_fingerprints.json)证明4类参数块变化。没有使用loss下降或参数变化代替策略收益。
- 原854项源码/配置不变；新增7项后绑定861项，新[资格](admission.json)为有界更新探针，硬上限16批，`runnable_trainer=false`。它不授权直接开展20,000周期短训。
