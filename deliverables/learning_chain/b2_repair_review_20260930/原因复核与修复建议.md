# B.2 上轮效果不达标：原因复核与修复建议

2026-09-30。用户要求检查上一轮原因并提出最有效的修复方案。本次是归档诊断和方案交付：生产代码未改，新增物理、actor/critic前向、优化均为0；没有新增执行资格。旧余19次/2000批不执行，自动跟踪不恢复，B.2未完成。

## 结论先行

**直接停机原因已确定：受阻接触中驱动参考领先，真实合力越过共同保护线，累计第三次合格力失败触发受控停止。学习层面已确定存在新危险边界的严重价值高估，以及预热随机动作与更新后持续偏置行为的明显差别；尚未证明唯一软件缺陷或哪一种修复必然最有效。**

当前优先选择是**只降低actor学习率，保留critic学习速度，做可复现的小对照并保留初始任务能力**。它针对“价值尚不可靠时策略变化过快”的工作假设，改动和归因成本较低，不是已经证明有效的根因修复。若对照不支持，下一项应讨论时间相关的探索/数据覆盖与控制时间尺度，不继续逐档降低学习率或增加旧轮训练量。

这份复核补充[9月29日草案](../b2_actor_lr_design_20260929/README.md)，不覆盖原草案、实验包或冻结合同。原草案的500批/四点评价只能筛查早期变化，不能作为2500批后危险状态已修复的结论。

## 2. 分层原因与证据强度

| 层次 | 已有证据 | 能说明什么／不能说明什么 |
|---|---|---|
| 运行可靠性 | 最近轮无原生崩溃或最终写入失败；10次写入重试恢复；退出20 | 原子写入修复没有在本轮再次失败；不能把正常保护退出当程序崩溃 |
| 直接物理机制 | 三次峰值0.025001818、0.025104987、0.025019905 N，阈值0.025 N；参考领先、真实停稳 | 越限真实存在。两次有恢复、一次没有，恢复故障不是统一解释；没有残差物理反事实，不能认定某单轴是充分原因 |
| 初始能力余量 | 初始确定性四点4/4，峰值距线约2.1% | 既有轨迹余量很小，持续小偏置也值得关注；不证明保护值错误或应该放宽 |
| 经验与标签 | 前两次失败入池，终奖−10，边界被抽样5116/2134次；随后边界一度拟合接近精确尾段 | “已见失败完全漏用”已排除。重复抽样不是新增危险状态覆盖 |
| 新状态价值 | 第9回合最后记录动作双Q为9.364/9.557；精确尾段−8.359，较小Q偏高17.722 | 明确的边界价值失真；该回合未进入此前训练，不能叫训练集误差；前置动作仍可改变，不把整条失败回报当所有前置Q的真值 |
| 行为与覆盖 | 随机预热每2ms独立采样；500批后出现连续同向请求，见下表 | 支持“动作范围覆盖不等于持续施力轨迹覆盖”；尚无因果隔离，不能直接证明降低学习率可解决 |
| 评价缺口 | 最终开发、恢复与独立评价没有执行 | 探索失败是负面证据，但不能用初始确定性4/4对比训练1/9，声称固定最终策略成功率已下降到1/9 |

本次新增的动作统计（X、Y、roll、pitch顺序；仅有动作权限的记录）：

| 记录 | 相邻活动周期同号比例 | 全活动段归一化动作均值 |
|---|---|---|
| 四个预热回合 | 各轴约49%～51% | 各轴均值绝对值均小于0.015 |
| 500批后的train_04 | 72.4%、69.7%、96.8%、88.6% | +0.482、+0.182、−0.599、−0.467 |
| 2500批后的train_08 | 99.2%、97.0%、89.6%、96.0% | −0.188、+0.846、+0.104、−0.707 |

预热请求积分的“净积分绝对值/绝对积分”约0～2.9%；train_04四轴为76.1%、77.5%、86.6%、96.1%。因此预热动作虽然覆盖[-1,1]，正负请求大多互相抵消；后续策略则长期向相似方向请求修正。**这些是请求统计，不是实际位移，也不证明持续动作本身有错。** 初始成功策略也有较高同号比例，但均值幅度较小；需要同时看幅度、状态、限幅和任务结果。

首次500批重复使用22,766条转移，actor抽样128,000行约等于5.62次整池行数。不能仅凭“500次”认定更新量异常过大；关键限制是只有四条高度相关的预热轨迹。第9回合前实际池中41,427条；47,474条包含触发停止后的第9回合，不能说2500批网络已经学习过全部47,474条。

## 3. 代码审查排除了什么，仍缺什么

1. 双critic取最小值、actor更新时冻结critic参数但保留动作梯度、目标网络软更新、温度损失符号和非活动动作屏蔽，在本次源码阅读中没有发现可直接解释本轮的接线错误。这是限定静态审查，不是全项目正确性证明。
2. 精确尾段目标确实覆盖最后可动作边界及后续无动作尾段，critic有16/256边界配额；actor保持普通抽样。前置可动作段仍使用一步目标，2ms折扣约0.9998，传播及覆盖仍是可能因素，尚不能直接替换成整轨迹失败标签。
3. 参考位置/转动误差已进入120维观测，不能把本轮简单归因于“策略完全看不到参考领先”。本次实际达到±10裁剪边界的维度仅为`stall_span_s`和`hold_elapsed_s`计时量，未发现力或参考误差被这条裁剪统一抹平的证据；这不证明观测充分或满足Markov假设。
4. 平均critic损失由前500批约1.039降到末500批约0.176，但新危险边界仍严重高估；损失下降不是任务改善验收。alpha末值约0.00986，也不能据此认定熵已失控。熵项与单步奖励绝对值的比例不是自动改奖励的依据。
5. **三个优化器目前共用`learning_rate`。** 单改公共值会同时减慢价值学习和温度学习，偏离原假设。检查点还会恢复Adam参数组，必须显式核对分支学习率，不能加载后被旧状态覆盖。

最有根据的工作假设是：**有限预热轨迹对持续偏置导致的接触状态覆盖不足，critic对新危险区域乐观；actor跟随不可靠的价值梯度产生较大行为变化，后续真实失败反馈的局部拟合不足以阻止进入其他危险状态。** 此链条中“覆盖不足导致高估”和“高估导致行为变化”的因果强度仍需要对照，不应把推断写成已定位代码bug。

## 4. 三种修复方向的取舍

| 方向 | 优点 | 当前取舍 |
|---|---|---|
| 仅actor 3e-4→3e-5 | 单变量、改动小；保留critic/温度3e-4，限制早期策略变化；能复用预热做配对 | **第一优先级。** 只是候选；不会自动补足危险状态覆盖 |
| 改成时间相关探索／调整策略决策时间尺度 | 更直接处理随机预热与持续动作的轨迹分布差异 | 若第一候选不支持，优先讨论；会改变探索或时间语义，需要新的有界预检、数据和预算，不在同轮叠加 |
| 增加critic更新、延迟actor、n步目标或保守价值正则 | 可能改善价值跟踪、传播或限制分布外乐观 | 不作为本次并行组合。已见边界能拟合，缺少证据认定“再多拟合”最有效；算法和调参变量更多 |

不建议放宽力保护、把失败去掉、再缩所有动作来掩盖学习退化、从停止的2500批直接续训、或重新执行同样的大轮。若需要改变基线Z推进/参考积分保护，那属于共同控制版本改变，需要同时重评B2，不能伪装成普通SAC单参数修复。

文献只支持候选的机制合理性，不证明本项目效果：[Fujimoto等（2018）](https://proceedings.mlr.press/v80/fujimoto18a.html)分析actor-critic近似误差与过估计，并研究延迟策略更新；它不是“actor学习率必须降10倍”的证据。[SAC原论文](https://proceedings.mlr.press/v80/haarnoja18b.html)采用最大熵随机策略，因此只检查确定性动作不足以覆盖实际随机采集行为。

## 5. 推荐修复方案及对旧草案的补充

### 第一步：有界实现准备

仅给actor增加独立、显式、有限正数的学习率字段；缺省兼容旧值。A=3e-4，B=3e-5；critic/温度均3e-4。配置版本、来源清单、检查点优化器参数组、默认兼容、跨分支恢复拒绝、回滚和预算预扣均纳入验证。生产源码修改前保存需要继承的旧字节；原包、合同、清单不改写。

本次只提出方案，没有实施。后续纯协议测试不调用真实网络/物理；原草案最多16次真实合成更新和128次额外测试前向仍须纳入单独授权。

### 第二步：固定预热的早期筛选

沿用原草案四份预热数据、两个分支各500批/各四点开发评价、A先精确复现历史500批的约束。4预热/0更新检查点不存在，必须从既有零更新状态和归档重建；无法精确复现则停止，不能临时补跑预热或扩大预算。

以下是此次建议补强项，尚未冻结为执行合同：

1. **同时检查策略均值和随机分布。** 在原定256个固定预热活动状态上，初始/A/B各一次actor分布参数前向，共768个状态前向。由同一组高斯均值/标准差得到tanh均值动作、解析每轴贴边概率和相对初始分布KL；不新增随机采样、critic评分或物理。这替代原768次仅确定性动作诊断，不能两套重复计算。派生公式先用不调用网络的解析样例验证；所读分布必须与实际SB3策略一致。
2. **先看干预是否起效，再看任务。** 汇总及逐轴报告B对初始的动作变化、贴边概率和分布KL，并与A比较，不把均值变小直接等同于随机探索安全。若只有均值变小而随机贴边风险仍高，候选不获得机制支持；不临时再改熵。
3. **保留初始能力参照。** 四点初始已有4/4；B即使比A好，但只有3/4，仍是未保持初始能力，不能称修复通过。工程可比、无保护/无效、B达到4/4且漂移相对A减小时，最多可记“早期能力保持与漂移改善”；A/B均4/4且任务指标无明确差异时只记任务优势未证实。初始历史档案只作参照，不新增本轮成功样本或声称重复性。
4. **评价只选预先固定的500批检查点。** 不根据Q、某个点成功或本次危险档案评分另选最好模型；报告全部点与负结果，载荷看周期峰值，效率只比较共同成功点。任何保护完成停稳归档后终止整个对照，未运行点记缺失。

拟议预算仍是1000批、最多8次动态，另列原16次合成事务、768个诊断状态前向和最多128个测试前向；诊断critic评分0。全部未授权，不占用旧余19/2000，也不恢复自动跟踪。

### 第三步：交互修复验收必须另立阶段

前两步即使通过，也不能回答“2500批后是否还触发第三次力保护”。后续需要新登记的在线采集—更新对照，固定观察窗口覆盖此前失败出现的阶段、保留原停止门，再做冻结最终开发、独立进程恢复及独立评价。两分支启动条件一致，但采集轨迹会随干预分叉，不声称逐样本相同。

这个后续阶段的预算尚未设计或授权，不能让早期筛选通过后自动接跑。真正的学习收益还要相对于初始策略和共同B2，在成功、载荷、效率上取得可重复证据；四点4/4是能力保持，不是创新收益或泛化证明。

若第一候选不能保持能力、仍触发保护或机制指标不支持，应结束此次学习率假设检验，转向时间相关探索/覆盖与控制时间尺度的方案讨论，不继续盲扫学习率。
