# B2-05｜无接触可辨识性、残差漂移与后续预检建议

2026-09-27。**离线诊断已完成；没有新增训练、物理回合或独立测试。** 本项核对B2-04的23份完整档案（7训练、16开发评价）和最终检查点，复核旧交付114个文件、872项生产/配置输入。新增的是解释和可复算证据，不增加装配样本数。机器结果见[diagnosis.json](diagnosis.json)，后续提案见[接触开发预检建议](下一项建议.md)。

## 结论与证据等级

1. **直接证据：** 8点评价在有动作权限时观测近乎相同（最大差5.68434189e-14）、归一化动作完全相同。相对起点观测、无接触反馈和一致控制器状态，使本组策略无法按不同初始孔偏差选择方向。现有数据支持这组轨迹上的不可区分，不能证明所有主动探测轨迹都不可辨识。
2. **直接证据：** 两训练失败和一评价失败在原停止后1s任务判定窗口内始终不满足XY精度。末端最后100ms的深度、角度、线速度、角速度均通过，载荷/接触记录为零。末端复算只是诊断，不重新授予额外成功机会。
3. **限定解释：** 对各个初始位置施加同一方向的小残差会帮助部分点、伤害另一些点，足以解释开发01从成功变为失败。网络为何学到该方向仍未唯一定位；不能把无接触首训负结果直接推广为接触纠偏方法失败。
4. **建议：** 先验证接触开发点的可观测信息和动作作用，再讨论新的小规模学习。暂不同时改奖励、熵、动作频率、观测或初始倾角。

## 观测—命令—运动—判据链

观测白名单见[observation.py](../../../tools/learning/observation.py)：`relative_position_m = position - initial_position`；力矩历史是最近4个控制周期，跨度6ms；参考误差是驱动参考位姿相对当前位姿，不是孔中心误差。`reference_qpos`在停止/恢复时会重置，不提供真实初始孔偏差。

同样动作、无接触情况下，位移、速度及控制器状态随各自起点平移而几乎一致。本组最大有效期观测差约5.68e-14，远小于可用于解释输出差异的量级；初始观测完全一致。停止后结果标志不同不代表动作仍能纠偏。[session.py](../../../tools/learning/session.py)在到达Z目标平面后停止并撤销动作权限；`TARGET_POSE_NOT_SETTLED`来自原任务观察窗口结束。不得为这次失败单独放宽停止/成功标准。

动作在[action.py](../../../tools/learning/action.py)映射为XY各150μm/s、roll/pitch各0.005rad/s的最大请求，并经过阶段/速度/加速度限制。固定开发SAC的**实际受限XY命令积分**为(14.913232, 15.362338)μm；实际最终位移(14.913774, 15.362784)μm，相差不足0.001μm，支持残差经执行器累积成平移的解释。

“同一个前次命令下的零残差限制器对照”积分为(11.373420, 15.362338)μm。它保留了实际历史命令，故与真正独立零残差轨迹不同；**不能把有效命令差积分当作物理因果位移**。真正配对B2的XY位移为0。训练随机动作的命令积分与实际位移也有有限差异，不将命令当实测运动。

## 训练域与成功域不是同一形状

工程采样是XY各±50μm的正方形，成功判据是XY范数≤50μm的圆，同时还要求深度、姿态、速度、载荷和连续保持。[原判据](../../../tools/validation/run_b1_baseline.py)保持不变。

**仅作几何推导：** 若XY均匀分布在该正方形，且无接触、XY不移动，则圆内面积比π/4≈78.54%，圆外≈21.46%。这是给定假设下的XY合格占比，不是测得成功率、算法上限或新仿真。7个实际训练初始点和8个固定验证点均在圆内，故本轮失败不能归因于恰好抽到正方形角区；固定8点8/8也不能证明整个方形域零残差都能成功。此前B1-06四角零残差失败与该几何关系一致。
