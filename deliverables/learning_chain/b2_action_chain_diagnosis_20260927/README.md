# B2-08｜动作到实际运动的数据链离线诊断

本轮完成11份已有档案离线核对，新增物理回合0、SAC更新0、独立测试未用。没有修改生产控制、模型、奖励、守卫或成功判据。当前证据支持“动作链路已接通，但早期接触状态下实际纠偏很弱”；尚不足以认定SAC算法失败，也不足以批准代表探索训练。

例如SEARCH X+：请求7.500μm，B2反馈差−2.718μm，限制差−0.762μm，合计参考约4.020μm，实际X末差仅0.001693μm。约78%的总命令减量由轨迹中的B2反馈差贡献。角脉冲约98%的减量来自B2反馈差。故“主要是限制器吃掉动作”的解释不符合这组积分账目。

`effective_command_delta`是同一状态下限制器的零残差反事实，不能替代两条真实轨迹的命令积分差。旋转非交换，跨完整窗口的旋转向量差与角速度积分差也不要求数学上完全相等；当前小角度同轴误差很小，非请求轴残差完整保留于JSON。

## 决策与下一步

不直接扩大训练资格。当前能排除正常段动作未接入、驱动力硬饱和及“限制器解释全部衰减”；不能排除接触状态依赖的作用，也没有识别唯一接触机制。先提出一个有限对照：[首次SEARCH累计XY运动达到5μm后，执行同幅同长±X脉冲，仅2回合](下一项建议.md)。这是基于开发档案的事后设计，尚未执行，完成本交付后先汇报。
