## 2. 假设与单变量边界

待检验假设：在仅有少量接触数据时，较快actor更新使策略偏离已有覆盖区域；减慢actor可能减少早期漂移。**现有证据没有证明actor学习率过高是根因，降低它也不直接修复critic对新危险状态的泛化。** 即使动作变化变小，仍须看实际任务是否退化。

| 设置 | A：原学习率对照 | B：候选 |
|---|---:|---:|
| actor学习率 | 3e-4 | 3e-5 |
| critic学习率 | 3e-4 | 3e-4 |
| 温度学习率 | 3e-4 | 3e-4 |
| 初始化、预热数据、抽样次序、更新批数 | 相同 | 相同 |
| 动作幅度、奖励、观测、物理版本、保护与成功标准 | 当前冻结值 | 相同 |

当前 `SACUpdater` 用同一个 `learning.learning_rate` 初始化三个优化器。**直接改该字段不是单变量修复。** 拟保留其3e-4默认行为，仅在新版本候选中增加显式 `actor_learning_rate`；A取3e-4、B取3e-5。同一实现运行两支，不把新增代码与原代码差异混入处理变量。critic/温度参数值会因训练反馈而产生分支差异，这是干预结果，不是第二个人为调参变量。

## 3. 推荐的有限对照：固定预热数据，各500批，各四点评价

问题限定为：**在相同四个预热回合上做第一组500批更新，降低actor学习率是否减小策略变化，并改善或至少不恶化固定开发评价？** 这不是完整重新训练，也不直接检验第9回合的再次力保护概率。

1. 从原初始完整检查点和train_00～03四份已审核预热归档，在新包内重建首组更新之前的学习状态。复用22,766条原经验，不新增预热、不重跑物理、不将其计为新增数据；不导入train_04及之后的数据，也不使用独立测试。
2. **不存在现成“4预热/0更新”检查点**：train_02为3回合/0批，train_03已为4回合/500批。不得把后者当初始状态。必须按既有记录恢复权重、空Adam状态、温度、回放/边界索引及全部随机流，核对四个回合的审核与来源。若无法准确重建，停止准备并报告；不临时补跑四次预热或增加优化预算。
3. A、B深复制同一个重建状态，网络/优化器/回放不共享可变存储，独立持有相同起始随机状态和预登记抽样序列。只改变B的actor学习率。A先执行500批；剔除时间戳/耗时/新资格路径等声明过的元数据后，学习权重、Adam状态、温度、计数、随机状态及抽样索引必须复现归档train_03。A复现失败即终止整个对照，不能调容差、重跑或转为只看B。
4. A复现通过后，B执行同样500批。批大小256，critic边界配额16，精确尾段、折扣、温度和目标网络设置保持。两支各500批后固定保存，禁止依据评分或某个物理结果挑选其他检查点。
5. 在冻结的预热活动状态子集上，比较初始/A/B的确定性归一化动作。每个预热回合按索引均匀选64条活动记录，共256条；按每轴均值/绝对变化/P95及绝对动作≥0.95占比报告，不以新轨迹选点。初始/A/B共768次状态动作推理。
6. 两支最终检查点在新进程只读加载后，各做原四个沿轴±100μm、零倾角的确定性开发评价，顺序固定为+X、−X、+Y、−Y，按点A/B配对记录。最多8次新物理启动；完整学习状态/RNG评价前后保持一致，评价经验不入池。新进程加载兼作本次保存/加载核对，不另加恢复动态回合。

冻结数据的优点是隔离第一次策略更新，避免两支因采集数据不同而难以解释；局限是预热中没有力保护样本，且不检验后续交互覆盖。历史初始4/4和同版本B2只作背景，不能替代这里的A支评价。两支相同结果也可能是测试太短或指标天花板，不能等价于假设已被彻底否定。

不推荐本轮直接两支完整12回合重训：计算和物理成本更大，采集数据开始分叉后归因更复杂。也不推荐只让B续接旧2500批检查点：那测试的是故障后恢复效果，回答不了减慢早期actor的假设，且不能绕开旧频率停止门。若要选这两种方向，应另行设计与批准。

## 5. 预先约定的判读与结束条件

- 先验收工程可比性：A复现、单变量参数差异、隔离、状态保存/加载、评价不污染、完整尝试账本。任何一项不符，对照不可用于判断学习率效果。
- 主要任务指标：四点完整成功数、每点结果与保护/有效性/停稳；同时报告终态XY和角度、深度、周期峰值力/力矩、成功配对点任务时间及残差实际作用。失败更快不能解释成效率更高。
- 机制指标：B相对初始的每轴动作变化及饱和占比对比A。动作变化小只说明干预起效；奖励或Q变化不单独充当成功标准。
- 有限支持条件：完整配对可比、B无新增保护/无效，B成功数至少不低于A，并出现动作漂移减小。若任务结果相同，只报告“漂移减小、任务优势未证实”；不以不足四点或挑选成功点宣称改进。
- 若B成功下降、发生保护、漂移未减小或比较不完整，如实报告候选未获支持或证据不足。本草案最多这一组A/B，不自动试3e-6、增加批数、改奖励/动作/熵、延长采样或增设critic优化。
- 即使有限对照支持候选，**也不能宣告危险状态价值已修复、2500批后稳定、学习一般性收益或B.2完成**。后续交互训练、恢复及冻结独立评价仍需新的完整方案；若继续不能形成可重复训练/评价，讨论覆盖和控制时间尺度，不围绕单个SAC参数无期限重开。
