# 100 ms预热候选：已批准的有界物理预检入口

沿用原工作树和全部未提交修改。用户在[具体方案](../b2_temporal_warmup_design_20261001/修复方案.md)交付后回复“继续”，授权完成适配、验证、最多8次新动态预检及结果收口；没有授权训练。

四个原开发点依次+X/−X/+Y/−Y 100 μm，各先A（每2 ms重采样）再C（100 ms保持）。每方向PCG64初始化相同，两臂共用新入口；禁用权限时不抽样。基线、动作尺度、2 ms转移、奖励和共同保护保持。任何接触或运动保护在完整归档/停止审核后停止余点；普通任务失败继续；异常不重试。每次复位前持久预留13000个控制周期，包含安全尾段，总上限104000周期/1040000子步。之前累计60次，本次累计上限68。

本入口不创建神经策略或优化器，不向经验池发布数据，不解锁旧账本，不恢复自动跟踪。物理子步逐次计数并检查本地活动账本，监督身份和磁盘所有权在每个控制边界、初始化及资格复核时检查。原始回合、采样转录、完整PCG和保持器状态均保存；独立离线恢复审核不新增物理。

`execution_pins.json`记录封存后的绑定与授权。使用已登记CPU解释器执行`run_preflight.py`并提供两个摘要；监督进程负责独占启动及工作进程生命周期。`--verify-only`只验资格，不执行物理。任何已尝试的本目录不能再次启动。采样覆盖门只在8份全部有效停稳且无保护后判断，通过也不等于策略修复或B.2完成。结果位置：`run/`和后续`result_analysis/`。
