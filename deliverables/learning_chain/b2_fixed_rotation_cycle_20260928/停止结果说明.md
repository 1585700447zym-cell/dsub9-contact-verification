# 固定转动残差候选：停止结果说明

2026-09-28，北京时间20:53停止，20:56跟踪发现。本轮未通过，B.2仍未完成；本说明交付失败证据，不是B.2验收通过报告。

## 发生了什么

新候选仅将roll/pitch各轴残差幅度缩小为0.0005 rad/s，其余共同设置保持。初始确定性四点评价4/4成功，评价前后学习状态未变。随后四个随机预热回合1/4成功，全部有效停稳、未触发保护，发布22,766条经验，完成500批SAC更新。

首次使用更新后策略随机采集的回合为正X100微米。回合先搜索耗尽，再回撤并恢复；恢复约0.7542秒后触发FORCE_LIMIT。仿真有效、已实际停稳，但接触保护未通过，6,293条经验全部拒绝入池。触发周期不再授予下一动作权限，后续周期动作均为零。监督进程以代码1退出，异常来自整回合审核失败；这次不是Python原生访问违规崩溃，也不是物理前入口拒绝或普通精度失败。

| 事件或指标 | 归档结果 |
|---|---:|
| 搜索耗尽 | 9.172秒 |
| 恢复运行 | 9.830秒 |

| 终态Z坐标 | −3.750013毫米 |
| 周期末采样穿透最大值 | 7.117689微米 |

力峰值仅比阈值高约0.00727%，仍按冻结规则判为保护失败，不调阈值追认通过。该精确峰值由原始周期奖励项还原；保护事件来自子步记录。周期末采样穿透不能替代原始子步峰值。终态仍处于回撤后的高度，较小姿态角不代表插入完成。

## 能说明什么，不能说明什么

- 只缩小固定转动幅度，仍不足以使这次有限训练流程通过。保护、停稳和整回合隔离按约定起作用。
- 初始4/4是零更新策略结果；四个随机预热与初始确定性评价的采样方式不同，不能据此推断训练让成功数从4降至1。
- 更新后只发生一次随机采集，不能当作固定最终策略成功率。最终对B2和对初始策略的收益均未验证；同DLL B2的3/4仍只作已有开发对照。
- 较小姿态、力阈值附近接触以及恢复时序提供了具体失败位置，但不足以证明唯一因果根因，也不能据此证明阶段自适应约束一定有效。
