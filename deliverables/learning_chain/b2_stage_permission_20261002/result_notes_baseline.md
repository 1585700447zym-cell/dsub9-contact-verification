# 当前轮纯 B2 四方向轨迹摘录

## 可以直接证实的结论

同版本纯 B2 在本轮四个开发点成功 3/4；负 X 回合为有效普通任务失败。四回合均已真实停稳、无保护，实际残差始终为零。当前共同基线确有一个终末 XY 精度未满足的开发点，不能假设纯 B2 已四点全成功。

负 X 的 `final_session.reason=TARGET_POSE_NOT_SETTLED` 不能解释成“物理未停稳”。原始 `outcome.physical_stopped=true`，末端深度、姿态、速度和载荷均通过，直接不满足项是 XY=61.099180 μm，大于 50 μm。停止后完整任务观察窗口内 XY 均不满足，因此没有可能建立全部条件连续保持 0.1 s 的成功判定。
