# E02 正 yaw 被动输出减权配对复测

2026-11-11 完成。以修复运行库下原 E02 为基线，仅新增一条 SEARCH 被动 yaw 输出乘 0.25 的确定性轨迹。初态 XY 为 (+320,+280) µm，yaw +1.5°，roll −1°，pitch +1°。采用同一第 101 次更新后的 GRU、物理和探索种子、900 µm/s 搜索及 30 秒决策预算。两条轨迹到首次 SEARCH 的 4.406 秒完全一致，4.408 秒出现第一个物理状态差异。通过附加审核的 6,430 个非零 SEARCH 被动 yaw 输出均符合 0.25 倍系数。

两条均满足 100 nm 几何容差，完成原生仿真、策略来源、被动状态递推和停稳审核。均未超过 5 N 或 6 N。成功时刻包含保持确认段，停止决策分别在 23.644 秒和 23.618 秒。力指标采用各自任务段原生 0.2 ms 采样。

原被动强度在正 yaw 下确实更充分地带动了负向调姿。减权后的第二轮搜索结束 yaw 高出约 0.338°，最终姿态也离零更远。减权轨迹通过较小的末态 XY 偏移及后续接触调整，仍达到九针同时配合。完成时间只差 26 ms，首次主孔时刻也仅差几十毫秒，单次结果支持任务表现相当。峰力上升约 0.099 N，RMS 和力积分变化很小。

搜索阶段被动输出积分从 −0.756° 变为 −0.254°，GRU 有效 yaw 积分从 +0.0254° 变为 +0.0240°。接触状态与力矩随干预改变，实际转角也相应变化。该实验的策略权重相同，体现了基础控制强度与完整闭环相互作用，不能作为新训练收益。

结合 E01，25% 设置把负 yaw 的失败从孔口推进到部分主孔配合，同时在这条正 yaw 开发工况上保留了成功和相近用时。因此 25% 可作为下一轮 GRU 训练的共同候选控制设置。现有两条开发配对只覆盖一个冻结策略和两个初态，普遍效果及最优强度仍需后续证据。负 yaw 的最终插入仍未完成。
