上述五项X积分满足“请求+B2反馈差+阶段裁剪差+速度/加速度限制差=配对命令积分”，基线和脉冲都沿各自反馈轨迹；这是加法分解，不是把B2关闭后的独立因果效应。接触力差按时间配对，驱动力和接触力采样在最后子步积分前后，矢量残余比例不能唯一判断摩擦、几何或求解器。原始参考差、载荷差、命令反事实、阶段转换和结局均保留在[机器结果](assessment.json)。

与B2-07早期SEARCH比较只解释同点状态下的响应变化。B2-07早期X−/X+最大位置差分别0.001749/0.001693μm。本轮对应1.983990/1.665720μm，约为早期的1135/984倍；参考仍只移动约4.173/4.486μm，变化主要体现在实际运动响应。后段载荷变化包含动态接触演化，不沿用早期近似静态抵消的解释。不能直接外推其他方向、持续随机探索、多种子学习或稳定装配收益。
