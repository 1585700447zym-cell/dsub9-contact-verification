## 固定采样与预算的实际含义

主种子2026092711，前三条随机流分别用于选点、预热、经验抽样。最多六次的选点顺序是：**正X、负X、负X、负X、负X、负Y**。等概率有放回采样不保证短批次覆盖四点，本种子没有正Y；达到目标后可能更早结束。保留种子和困难点，逐点报告实际访问数；四点开发评价仍各执行一次，禁止当作独立泛化测试。

最初累计审核数<5,000时整回合采用预热；此后每4个新增审核转移产生1批更新信用，更新在审核发布后执行，下一回合开始前耗尽已获信用。通用上限8,250仍保留，但在总审核量<33,000的本次预算下理论最多6,999批，不能承诺达到8,250。六次启动耗尽而20k目标不足时如实结束，不补采。

## 尚未接通的执行边界

1. 正式采集器：旧[范围校验与采集](../../../tools/learning/admitted_collection.py)只接受工程资格和±50μm，且新方案要求保护触发回合在发布前隔离。
2. SAC链路：旧[采样/更新链](../../../tools/learning/sac_collection.py)和[更新器](../../../tools/learning/sac_update.py)严格校验工程配置；新种子、范围和资格需共同适配。
3. 检查点：旧[保存恢复](../../../tools/learning/sac_checkpoint.py)校验工程范围、重建EngineeringSampler，不能直接恢复四点采样器。
4. 训练驱动：旧[短训驱动](../../../tools/learning/engineering_training.py)没有本次六启动上限及更严格的保护停止要求。
5. 开发评价：旧[评价器](../../../tools/learning/engineering_evaluation.py)固定原8个small_xy工况；新版本应固定四点各一次，保持评价经验隔离。
6. 正式资格：新执行代码完成并检查增量、测试和恢复证据后，才可另生成正式资格。本准备记录永久保留false，不原地提升权限。

这些是同一接触执行适配交付中的边界，不是六轮新物理诊断。具体合同见[范围与执行边界](范围与执行边界.md)。
