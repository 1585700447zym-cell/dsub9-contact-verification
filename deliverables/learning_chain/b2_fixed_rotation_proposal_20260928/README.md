## 1. 要回答的问题

在相同学习实现、种子、工况和预算安排下，缩小固定转动残差权限，是否能减少已观察到的持续倾斜，并保留位置纠偏能力？本次服务于B.2的有限基线修正，不实现阶段或进展相关缩放。

当前证据是行为线索，不是唯一因果根因：更新后六次随机采集均未完整成功，三次到达目标深度但停止尾段姿态仍为0.96～1.29度；首个更新后回合roll请求在96.8%的有权限周期贴近边界。第10回合穿透保护退出，未完成最终固定策略评价。不能把不同中间策略的0/6当最终成功率，也不能认为缩小幅度必然解决穿透保护。

原配置继续训练无法单独检验此假设；同时修改奖励、策略更新规则或增加阶段机制又会混合多个因素。因此本次只选一个固定幅度，不进行参数扫描。完整原幅度运行尚未取得最终评价，后续新结果也不能包装成两个完整训练实验之间的严格因果比较。

选择依据来自已有开发数据，不来自独立评价：

- 旧初始策略四点评价成功4/4，转动残差请求模长均值约0.000511～0.000585 rad/s；对应有权限时长8.042～10.758秒。成功不证明转动请求的因果收益，但提供一个已经实际出现过的较小量级参照。
- 新候选双轴请求模长最大为 `sqrt(2)×0.0005≈0.000707 rad/s`，与上述均值同一量级，同时保留四维动作能力。不能把“模长均值”和“逐轴上限”说成完全相同。
- 仅为理解尺度，双轴同时饱和持续10秒，其请求角速度模长的时间积分约0.405度；旧上限为4.051度。新上限持续完整20秒仍约0.810度，超过0.5度成功阈值。**这是请求积分，不是实际姿态预测或安全上界**；总命令限制、基线反馈、动力学和接触都会影响真实运动。
- 该值是一次有依据的保守候选，不宣称最优或已完成公平调参。若失去纠偏能力、学习仍退化或出现新的失败，保留结果，不临时换到其他幅度。

平移映射、观测、奖励公式与权重、网络、学习率、熵设置、种子、精确尾段目标、critic边界配额、B2控制和恢复规则均保持。动作变化引起奖励数值及访问状态变化属于实验效应，不是保证它们逐条不变。

本方案构成训练合同v3动作映射的一项**候选版本化补充**；旧合同和旧配置不覆盖。仅在本方案获准、相关实现与资格验证完成后，新配置才可执行。孔几何、运行库、0.5度成功门、30微米穿透保护及其他共同保护均保持。
