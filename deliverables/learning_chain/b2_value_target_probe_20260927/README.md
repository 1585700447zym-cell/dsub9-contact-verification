## 这次对照证明和没有证明什么

- 在同初态、同数据、同抽样和相同更新次数下，只改变最终无动作尾段的目标构造，即显著改善终末拟合。这支持原有一步目标在本数据/预算下的回报传递效率不足，不能只笼统解释为网络完全学不会。
- 终末拟合不能代替纠偏价值判断。四个训练回合在最后可动作时决策标志均为None，下一周期为TARGET_PLANE_REACHED；成功标志在121个周期后出现，失败标志在501个周期后出现，均晚于动作权限关闭。结果已明确后的观测容易解释终末回报，不能证明结果尚未明确时也能判断。相关分段误差见assessment.json。
- 本轮每组256,000个抽样位置中，最后可动作四行分别抽中11、11、16、7次，合计45次；终末四行分别14、11、9、7次。精确重建索引与运行摘要一致。完整尾段标签有4,004条，并不等于关键可动作边界得到了同样密集的训练。
- 目前不能区分边界采样不足、观测对成败的可分性和函数拟合互扰各自的贡献；也不能把某个训练成功轨迹的实际回报当作任意动作的反事实价值。

下一项建议先做零物理、零更新的边界观测与样本分布检查，确认明确结果标志出现前的成功/失败状态能否区分，再决定是否需要一次有界、单变量的边界采样对照。暂不扩大物理训练，不同时改奖励、熵和观测，不承诺追加步数即可超过B2。

## 对照设计

两组从 B2-13 同一个最终检查点、相同 critic/目标网络/Adam 状态出发；使用相同经验索引和固定策略的下一动作样本。一组保持一步目标；另一组仅对最后可动作转移及之后完整无动作尾段，使用原奖励和原逐步折扣计算的剩余回报。22,722条原训练经验中4,004条满足这一条件，中途暂停后恢复动作的部分不替换。

登记每组1,000次critic更新，策略/温度冻结；只比较已存训练与开发轨迹上的终末、停止尾段起点和最后可动作状态的价值误差，不进行物理评价、独立测试或部署。诊断阈值预定各组最大绝对误差≤1且MAE较初值降低≥80%，不改变原装配成功标准。

## 首次尝试为何作废

新增诊断脚本 `make_policy` 向两个 CPU 优化器传入同一份保存状态，`load_state_dict` 保留了内部张量存储引用。权重虽不同，两组的 `step`、`exp_avg`、`exp_avg_sq` 与读取到内存的源状态共享存储。因此各组的更新相互影响，无法作为单变量对照；收尾检查要求各组Adam步数4430+1000=5430，实际未满足，入口失败退出。

直接的零更新复现确认三方张量地址相同，两个反例检查先失败。这个错误发生于本次新写的双分支诊断脚本，不能据此把原B2-13训练判为同类故障。源检查点磁盘文件未写入；旧61文件与879输入在修正版预检中再次通过校验。

原始证据完整保留：[首版方案](protocol.json)、[首版脚本](probe.py)、[启动绑定](run/started.json)、[失败记录及全部损失历史](run/failure.json)。失效尝试的2,000次更新计入实际消耗，不能因作废而从预算中抹去。首版未成功保存最终模型和价值测量曲线，不从中推断哪组更好。
