# 多针连接器E01的X单向累积与Y末态诊断

2026-11-13｜B.2只读分析完成，新增训练0、仿真0。

**核心发现：不能将两组GRU的末态正X偏离直接解释为GRU输出正X残差。** A的X残差确实总体偏正；B的X残差总体偏负，却同样出现正X漂移。共同出现的是未能进入主孔后，基础螺旋搜索反复耗尽、恢复，并以当前位置重设搜索中心。

冻结参数spiral_radius_m=0.0004、spiral_pitch_m=0.0001；theta_max=2πR/pitch=8π，螺旋目标R(cosθ,sinθ)终点相对于本段中心为(+0.4mm,0)。search_recovery.py的_start_search每次将search_origin设为当前位移、theta置0；恢复不会自动将XY移回最初孔中心。reference_search.py沿该局部中心跟踪螺旋参考。因而每段局部半径受限，不等于全任务位置相对最初孔中心不累积漂移。

B_E01事件记录明确显示四次SEARCH_EXHAUSTED，然后进入下一段SEARCH。五段搜索起点依次为：

| 起始时间/s | X/mm | Y/mm |
| --- | ---: | ---: |
| 3.454 | 0.298 | 0.421 |
| 9.734 | 0.630 | 0.346 |
| 16.012 | 1.009 | 0.247 |
| 22.292 | 1.384 | 0.148 |
| 28.570 | 1.761 | 0.048 |

末态X=1.916mm、Y=−0.018mm。A也有五段SEARCH，起点X约0.309→0.603→0.942→1.276→1.612mm，末态1.793mm。每段真实X净变化约0.3—0.4mm，主要发生在SEARCH内；恢复/卸载阶段本身的X变化很小。B全任务实际X增加1.636mm，其中SEARCH标记周期增加1.618mm；A对应1.513/1.482mm。标记周期包含最后停止尾段，命令统计与位移统计均止于task_end，不包含后续审核时间。

这揭示了本轮失效链条：没有及时捕获主孔→完整搜索耗尽→当前位置成为下一个局部中心→下一轮朝固定相位的螺旋端点推进→X偏移逐段保留并累积。螺旋理论参考终点与实际末态不是同一个量，接触、参考跟踪和残差会改变具体净位移，不能机械地按每轮精确0.4mm计算。

## X残差的方向并不相同

| E01的SEARCH命令记账 | A原奖励GRU | B新奖励GRU |
| --- | ---: | ---: |
| 同状态零残差命令的X时间积分/mm | +1.370 | +2.803 |
| 有效RL残差X时间积分/mm | +0.406 | −0.751 |
| 合成命令X时间积分/mm | +1.777 | +2.052 |
| 实际SEARCH期间X位移/mm | +1.482 | +1.618 |

A的正X残差在命令层面加重正向趋势；B的负X残差在命令层面抵消一部分正向趋势，但没有阻止反复搜索及中心外移。因此不能说B不会负X纠偏，也不能仅根据末态X判定其X残差为负作用。

表中的“零残差”是沿各自已存状态逐周期重组的局部参考，不是另跑一条关闭RL的轨迹；不同组访问的状态不同，不能把两列相减当作独立基线效果。命令积分不等于实际位移，差额包含接触动力学、驱动跟踪及状态切换等因素，本次没有将差额全部归因于接触。

## 为什么Y看起来好一些

B_E01确有较多负Y修正，最终Y比A更接近零。但螺旋转满四圈的参考终点恰在+X方向、Y≈0，所以失败重启本身对X/Y就不对称；同时Y受到残差、接触和实际结束时相共同影响。不能由末态小Y推断全程找孔质量好。

B_E01的Y轨迹在各段搜索中反复摆动，五次起点从+0.421mm降到+0.048mm，截止时约−0.018mm；此时X已经1.916mm且没有主孔配合。先前只读诊断还显示，B首次SEARCH一秒的Y残差为正，负Y纠偏并非一开始就稳定存在。E02也不能说B的末态Y最好：A约+0.014µm、B约−18.246µm、C约+7.846µm；B属于绝对偏移较小，但不是优于另两组的证据。

## 为什么普通SAC未出现同样E01漂移

C_E01只经历一段SEARCH（约3.236—8.330秒），随后转入INSERT并于8.642秒达到九针主孔配合、13.614秒完成任务。它在搜索耗尽前找到配合入口，因此没有进入这条多次重启、中心逐段外移的失效路径。不能据此断言GRU内部特有“X漂移机制”；更合理的表述是，本轮GRU未及时入孔，暴露了共同基础搜索在失败重试时的单向累积模式。C在其他失败初态是否也会出现同样模式，本次未新增验证。

下一项若继续，可以先用已有失败训练轨迹检查该模式是否跨架构出现，以及提取每段螺旋目标/跟踪分量；这比直接认定GRU应增加X奖励更有针对性。本次未修改控制器、奖励、限幅、准入或成功判据，未追加训练和仿真。
