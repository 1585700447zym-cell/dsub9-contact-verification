# B2-14｜学习效果与关键瓶颈审查

2026-09-27。只读核对 B2-13 的 4 个训练回合、4 个开发评价回合、最终检查点和全部 4,430 批更新，复用 B2-06 四点基线。**新增物理回合 0、优化更新 0；生产代码、冻结合同和旧封存文件未修改。**

结论：残差 SAC 有改善 B2 的空间，但没有本次短训必然改善的理论保证。本次新增的直接证据是：**最终双 Q 网络在已经见过的训练数据上，严重低估终末成败回报；到达无动作停止段起点时，成功与失败的剩余价值几乎没有拉开。** 这比“训练步数少”更具体，但仍不是已经通过干预实验确认的唯一根因。

## 理论预期与实际目标

执行接口支持零残差，能复现 B2。因此，如果优化相同的评价目标、可选策略包含 B2、并找到全局最优，最优值可以不低于 B2；严格更好还要求存在可利用信息和可行的改善策略。这是条件推论，不是实际训练保证。

实际 SAC 同时优化奖励与策略熵；原论文的精确软策略迭代保证针对相应软价值和理论假设，神经网络 SAC 使用近似价值估计与有限梯度更新。不能把该定理解释为“每次短训后，确定性策略成功率必然超过手工基线”。见 [SAC 原论文，第 3.2、4.1、4.2 节](https://proceedings.mlr.press/v80/haarnoja18b/haarnoja18b.pdf)。残差叠加会与基础闭环和环境动力学耦合，并不自动保留基础控制器的任务表现，见 [Residual RL 原论文，第 III 节](https://arxiv.org/html/1812.03201)。

当前奖励是推进增量、时间、力、力矩和一次终末奖惩。它没有连续 XY 精度奖励，也不是“所有工程指标同时改善”的目标。四个训练回合推进奖励都约 4.998～5.000；主要成败区别在最后的 +10/−2。成功总回报 13.403/13.682，失败 1.650/1.661，故本组数据不支持“奖励把失败排在成功前面”。

但同为成功时，XY 更小不必获得更高奖励：正 X 开发点误差从 B2 的 12.295 μm 增至 SAC 的 30.658 μm，总回报仍从 13.42460 增至 13.44306。时间与累计载荷项可以抵消误差变化；峰值力与累计力惩罚也不是同一指标。调整奖励属于研究目标决策，不能据此擅自增加孔中心真值观测或改变成功标准。

## 新发现：已见训练样本的价值拟合明显不足

下表在最终检查点上前向计算。选取动作已经禁止、之后一直使用零动作的尾段，因此剩余实测奖励不含未来策略熵，不把普通回报与有动作阶段的软 Q 混比。Q 为两个 critic 的较小值；两个网络均低估，完整数值见 assessment.json。

| 训练回合 | 结果 | 最后一步真实奖励 / Q 估计 | 停止尾段起点实测折扣回报 / Q 估计 |
|---|---|---|---|
| 000000，正 X | 成功 | 9.9998 / 0.8739 | 8.0178 / −0.0122 |
| 000001，负 X | 失败 | −2.0002 / −0.2074 | −1.8090 / −0.0170 |
| 000002，负 X | 成功 | 9.9998 / 0.8611 | 8.0178 / −0.0155 |
| 000003，负 X | 失败 | −2.0002 / −0.2072 | −1.8089 / −0.0148 |

最后一步没有后续自举，其目标就是即时奖励，因此这一误差直接说明已见终末样本的拟合不足。尾段起点的结果进一步支持成功价值尚未充分向前传播。它没有证明给 actor 修正价值后一定能找到成功动作，也不能单凭四条轨迹评价所有状态的价值准确性。

### 为什么这个问题容易被平均训练损失掩盖

- 22,722 条经验来自仅 4 个整回合，非零终末奖惩只有 4 条，占 0.01760%。500 Hz 的相邻转移不是 22,722 次独立装配尝试。
- 根据原采样规则、种子和每批池大小，仅重建索引。全部日志的动作权限计数、奖励绝对均值和最终回放随机状态均吻合。共 1,134,080 个抽样位置，终末行被重复抽中 187 次，按回合为 78、67、26、16 次。
- 仅 181/4,430 批包含终末行，4,249 批不含，占 95.91%。不含终末行的批次仍可通过自举学习，不等于它们没有学习价值；但小的批次平均损失不能代表成败价值已拟合。
- 4 个回合的最终无动作尾段均为 1,000 个 2 ms 转移。当前是一阶自举目标加慢速目标网络更新；终末信息向可动作状态传播的路径长。
- 2 秒的折扣仍为 0.81873，因而不能说终末奖励被折扣抹掉。问题证据集中在拟合与传播，而非奖励没有发放。

**证据等级：** 终末价值低估、实际抽样稀疏和长尾段均已确认；“这些因素各自导致了多少策略性能损失”尚需一次固定策略的对照验证。

## 其他已经确认的限制

1. **覆盖设计不足。** 实际正 X 一回合、负 X 三回合，两个 Y 点没有训练；只进行四次采集后的成批学习。B2-11 已预演出前六次采样不覆盖正 Y，这个预算设计适合执行验证，却不适合宣称四点效果验证充分。冻结后不能临时换种子挑选结果；应在下一版方案中事先规定覆盖规则。
2. **效果空间存在，尚未稳定学到。** 负 X 的一次随机 SAC 训练回合成功，另两次失败，最终确定性评价也失败。这说明已有允许动作轨迹能够成功，但不是已取得可复现的改善策略。
3. **观察限制仍在，但不能照搬旧诊断。** 四点评价初始观测完全相同，接触前策略平均动作相同；首次接触约 0.35 s。接触后动作均值已有差别，不再是旧无接触试验的全程相同输入/输出。是否足以稳定识别纠偏方向仍未验证；120 维及 6 ms 力历史不自动等于完整状态可观测。
4. **熵尺度是次级线索。** 最终网络在各训练回合有动作权限行上，采样熵奖励均值约 0.00715～0.00719，即时奖励绝对均值约 0.00110～0.00128。它提示需检查时间尺度配合，但量级比较不能证明熵梯度支配学习；不据此直接更改 alpha。

开发评价仍是 SAC 3/4、B2 3/4。X 两点误差变大、Y 两点变小，峰值力均略升，未取得一致收益。单种子、四个开发点不能证明 SAC 无效，也不能证明方法优越。

## 对此前工作顺序的复盘

此前确实排查了问题：旧工程范围无接触时不同偏差不可区分；动作链并未断开；早期命令受基础闭环及接触作用明显削弱，而后段能产生微米级影响；实际采集、更新、停止和恢复已有证据。这些减少了把仿真/接口错误误当算法结果的风险。

但此前在执行准入、局部动作检查及分阶段文档上花了较多工作，**对“价值网络是否学到了成功”这一直接学习问题检查偏晚**。B2-05 已提示稀疏终末和 1,000 步尾段，B2-11 已知覆盖不足，应更早把终末价值拟合与采样覆盖作为效果诊断核心。不能用通过了多少检查来回答策略为什么没改善；也不能把多次“继续”形成的历时当成充分训练量。

## 下一步建议与停止条件

优先提出一次零物理回合、固定 actor 与温度的价值学习对照，使用独立诊断副本，比较现有一步自举与**对已审核、未来动作恒为零的停止尾段计算精确剩余折扣回报**的目标。后者保留原奖励和全部停止审核，仅检查终末信息传递；不把历史候选自动转为正式训练经验，也不将诊断网络部署为策略。

该对照应先冻结更新预算、使用同一初始检查点和数据顺序，并分别报告终末拟合、尾段起点及最后可动作状态的误差。若终末拟合仍不成立，继续定位表示/目标问题；若成立，再讨论按四点完整覆盖组织的新训练预算，检查负 X 是否改善且不损害已有成功点。不要同时改奖励、熵、观测和动作频率，否则无法知道哪项起作用。

**此处是待沟通的对照方向，尚未实施或获得新增更新授权。当前证据不足以负责任地承诺“再训练多少步就会超过 B2”。**
