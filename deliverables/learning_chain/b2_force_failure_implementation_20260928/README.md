## 实现行为

新增版本化审核规则。默认仍执行原guard_clear规则；准备版仅接纳完整审核合格的单独FORCE_LIMIT。它仍为CONTACT_GUARD失败，guard_clear仍为false，−10终末奖励和原始停止尾段保持。穿透、力矩、运动违规、数值异常、停止不合格、动作/观测/奖励不一致或真实运行故障继续拒绝。

审核覆盖范围、全部物理子步计数、逐行与总事件一致、冻结采样时钟、停止窗口、回合内策略冻结、动作映射、观测连续性、折扣和唯一终奖。采集终审、整回合提交、更新信用、尾段目标、检查点重建及策略评价共用同一规则。新检查点有独立状态版本；旧默认调用和独立B2动态范围门保持严格。

合格失败正常完成经验提交后，在未触及频率界限时允许下一回合；累计第三次或连续第二次力保护触发协议停止，保留已发生的数据，拒绝后续更新及启动。这是待新执行方案冻结的资源控制上限，不是新的物理安全阈值。0.025 N、穿透和运动守卫、奖励、SAC计算、四维幅度及种子均不因此改变。
