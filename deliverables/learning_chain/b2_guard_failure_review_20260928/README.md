## 已确认的问题与证据

训练合同v3区分数值无效、有效保护失败和普通任务失败，并允许审核合格的保护失败保留。工程范围记录也要求由B.2正式适配裁决；它没有给任意保护失败自动学习权限。四点有限方案后来明确采用“所有守卫均无违规才能入池；任一保护即结束整轮”的更严格规则。本次停止符合原授权，不能把它描述成擅自丢数据的程序错误。

目标回合的数值和观测有限，63,930个物理子步均经过守卫检查，无数值/运动/穿透/力矩保护原因；实际完成停止，恢复之前的STOPPING不冒充最终停止起点。动作、观测连续，完整回合只有末行terminated，未伪造截断。策略在回合内保持500批更新状态；保护触发后取消下一动作权限，后续动作归零。原始fault仅为采集器主动写入的`contact_publication_rejected`，没有引擎或审核异常。

## 限定工程可信性的依据与边界

候选沿用同一修复版运行库、四个100微米沿轴零倾角工况、固定小转动幅度、原驱动/几何和全部共同守卫。本次力峰值0.0250018176 N来自周期奖励的冻结公式，停止由原始子步守卫触发。无PENETRATION_LIMIT意味着在已绑定守卫的覆盖下未记录超过30微米的穿透；周期末采样峰值7.117689微米本身不能证明子步最大穿透。真实逐子步事实与采样曲线必须区分。

合同和现有联合审核足以支持“将这个实例作为限定失败学习路径的验证夹具”，不支持连续域、任意力峰值、所有保护类别或真实接触载荷标定。0.025 N仍是物理停止阈值；不因此次超限很小而改阈值，不用单例超调值发明新的通用安全上界。未来每个候选失败都须在新资格下重新审核，不能只检查FORCE_LIMIT字符串。

## 建议修订的规则

| 情况 | 物理处置 | 数据与整轮处置 |
|---|---|---|
| 成功或普通有效任务失败 | 沿用停止与完整审核 | 原处理保持，分别+10/−2 |
| 单独FORCE_LIMIT，处于登记范围，全部其他有效性及停止/数据审核通过 | 立即停止本回合，保留完整停止尾段 | 记失败与−10；整回合可发布，不记成功；在预算和失败频率限制内允许下一回合 |
| FORCE同时伴随穿透、力矩或运动违规，或仅这些其他违规 | 原物理停止保持 | 本限定修订仍拒绝并停止整轮 |
| 非有限、引擎异常、严重穿透、停稳不合格、策略回合内改变、资格或归档错误 | 现有故障处置 | 整回合隔离，立即停止整轮 |

所有准入条件须绑定同一个版本化审核结论：数值有效、其他违规为空、完整子步覆盖、真实停止审核、范围合法、观测/动作/奖励/终止连续一致、回合内策略冻结、资格与文件摘要有效、无真实运行故障。`guard_clear`仍如实为false，不能把它改成true来绕过旧门。诊断脚本对历史`contact_publication_rejected`标签的解释仅用于追溯，生产实现不得笼统忽略fault；新流程应把“已审核的保护失败”与“运行故障”分开记录。

作为后续有限方案的**待冻结资源停止规则**，建议12个训练尝试中累计第三次或连续第二次合格力保护时停止后续更新和启动；所有已发生回合均保留，达到界限的回合也不能删去。本数字是控制失败重复成本的管理上限，不是物理安全界限或算法收敛定理；需连同新执行预算明确登记，不能加入当前已关闭的运行包。单独一次失败才有机会经后续更新学习；再次高频失败则结束，避免无限续训。

6. **监督、报告与停止频率**：将可信失败记为完成的失败回合，真正的故障才进入异常退出路径；频率界限及预算结束独立记账。不得只移除`Physical audit failed`抛错，否则前面仍丢数据、后面仍拒绝恢复。
