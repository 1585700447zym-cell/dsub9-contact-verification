## 修复内容

- [学习率解析](../../../tools/learning/learning_rates.py)与[SAC接线](../../../tools/learning/sac_update.py)支持独立 `actor_learning_rate`。A支actor=3e-4，B支actor=3e-5；critic和温度均保持3e-4。缺省仍使用原公共学习率。
- 恢复前核对三个优化器的全部参数组，非法、非有限、缺失及跨分支学习率在修改权重、温度、优化器或随机状态前拒绝，防止旧Adam状态覆盖候选学习率。此校验补充原完整检查点结构校验，不能替代后者。
- [准备类型](../../../tools/learning/actor_lr_preparation.py)绑定父配置、分支和当前源码清单；预测、公开/内部目标、更新入口均封锁，准入始终拒绝。本项绑定是准备身份记录，不是完整检查点加载器或执行资格。
- [随机分布诊断](../../../tools/learning/policy_distribution_diagnostics.py)按tanh高斯计算每轴贴边概率及candidate相对reference的KL，另报确定性tanh均值动作；它不是随机动作期望，也不保证时序相关性或物理安全。

此候选检验“actor相对critic更新过快”的假设。历史危险边界价值高估和动作持续偏置有证据，唯一学习原因仍未隔离，降低actor学习率是否有效尚未知。
