# B2-5.3 X 工况短时暂停额外横向搜索

冻结日期：2026-09-22。首轮仅运行 X +100 μm 一例，暂停参数在运行前确定；无论结果正负均保留，不根据首轮结果在本细分内改参数反复寻找成功。

问题：此前 V1/V2 的搜索退出同时改变 XY 与 Z 规则。这里与已冻结 V2 比较，仅改变额外 XY 搜索分量，检验短时停用它能否改变受阻及推进；不修改原九份模型、执行器、B1/B2/V2 源码。

## 干预规则

- 仍用 V2 的第二次搜索与原退出资格；首次搜索和回撤不改变。
- 第二次搜索相对起点推进达到原 0.10 mm 时启动一次试探。触发不读取真实孔偏差，不表示已脱困。
- 额外 XY 搜索项定义为螺旋切向速度加轨迹跟踪修正，不包含力导纳 XY 修正。
- 从触发观测时刻开始，额外项增益置 0，持续 1.0 s；随后 0.1 s 用 smoothstep 从 0 恢复到 1。仍保留原 SEARCH 的 XY 分量速度上限与执行器加速度限制；实际 XY 运动不会瞬间停止。
- 原导纳状态每步照常更新，Z 力反馈、角速度、退出门槛、保护和恢复规则保持原实现。
- 原螺旋相位/半径继续按每次控制调用演进；搜索起点和 phase_start 不重置。时间、半径、实际横移界限优先按原逻辑检查。暂停不增加搜索预算。
- 恢复时追踪继续演进的原螺旋，而不是重设起点；0.1 s 增益渐变限制额外项恢复突变，原限速与加速度限制继续作用。此设计的恢复过程也是本次干预的一部分，不能把全回合差异解释为“永久取消搜索”的效果。
- V2 原退出资格成立时立即按原逻辑进入 INSERT，不等到 1 s 结束；保护或预算耗尽同样可提前结束。每回合最多启动一次试探。

选择 1 s 的理由：触发处整体推进约 0.080 mm，V2 深度门槛约 0.350 mm；无载 SEARCH Z 指令为 0.4 mm/s，跨越该距离名义约 0.675 s，再考虑 0.05 s 资格保持。1 s 给出一个有界检验窗口。这是基于旧轨迹的开发参数，并不保证受接触时能达到该深度。
