# 新版 B1/B2 七工况配对重评协议

2026-09-23，运行前登记。用户同意的下一项完整能力：新版共同环境传统基线对照、准入审查与月报。执行沿用现有独立工作区；不新增候选控制参数，不启动SAC。

- 环境：核验实际导入路径与DLL哈希均与上一项隔离3.13.0记录一致。native、ccd容差1e-12、256段、物理0.2ms、控制2ms；几何/材料/驱动/保护保持冻结。
- 工况：run_b1_baseline.cases()中7个原开发工况，每个分别B1固定导纳和原B2固定配置，共14回合；从原七工况索引读取B2配置。每个回合新建环境与控制器，不跨回合残留状态。
- 公平预算：B1和B2均20s最大主动预算、原1s最终观察、原FINISH完整成功判据，B1原无进展停止规则与B2原搜索/恢复逻辑不修改。原算法允许成功或失败提前结束。
- 结束后统一被动延续至最终停止时刻+2s，期间不再运行策略，不新增成功机会；记录每物理步停止速度。只有原回合判为成功、追加观察末端仍满足完整位姿/保护/连续0.1s速度标准才算完整成功。保留原始成功列与完整成功列。
- 正常受阻、超时、有效保护失败不是数值错误。非有限数、引擎警告、INVALID/SIMULATION_ERROR/OUT_OF_BOUNDS为无效记录；保留但不得进入经验池。超保护门槛回合单列，若有对应保护事件并有效停稳可作为失败样本设计依据，不得当作安全成功。
- 物理停稳与全回合安全分别判读；继承stop_qualified的严格安全列，不通过扩大阈值补救。不能只因位置净变化小就忽略速度不合格。
- 若发现无效仿真或停止失败，报告阻塞并保留其余预定比较，不扫描参数。若出现同类致命软件错误则停止该工作进程并先修复，必要重跑另版本化。
- 数据集沿用原32验证/64独立测试清单，仅核对用途和哈希；本项不运行独立测试、不用于选参数。七工况不能冒充泛化成功率。
- 准入输出：全矩阵可复现、无共享数值/停止阻塞后，准入残差接口实现；真正首次短训仍需零残差等接口测试和训练分布初始化检查。若阻塞存在明确列出，不通过缩小范围绕开。
- 月报输出：完整七工况配对表、成功/失败与峰值载荷对比、至少代表性真实轨迹图、后续训练接口边界。不开启GPU训练，不替换正式3.9环境。
