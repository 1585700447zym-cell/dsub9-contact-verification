# 回撤后退出搜索的状态诊断

以下是本轮冻结策略的轨迹分析，不修改本轮策略、不重新判定任何成功。

| 工况 | 回撤后退出搜索时推进/mm | 之前受阻时推进/mm | 是否尚未回到受阻位置 | 最终结果 |
|---|---:|---:|---|---|
| 单独 X +100 μm | 0.080088 | 0.250013 | 是 | 到达目标深度，但完整位姿标准未满足 |
| 单独 Y −100 μm | 0.072584 | 0.250013 | 是 | 搜索预算用尽 |
| Roll +1.5° | 0.081568 | 0.225670 | 是 | 搜索预算用尽 |
| 联合 A ×0.75 | 0.089534 | 0.232811 | 是 | 搜索预算用尽 |
| 联合 A 全幅 | 0.083492 | 0.225123 | 是 | 搜索预算用尽 |

当前退出搜索条件是“相对这次搜索起点净前进0.10 mm”。如果起点位于回撤后的低处，这0.10 mm可能只是重新接近入口，并不能证明已经越过之前的受阻位置。
这不是虚构运动：前进量来自真实积分；问题在于该进度条件是否足以代表搜索获得有效对准。
对出现上述现象且随后再次受阻的回合，一个待检验解释是：第二次搜索过早退出，随后又因两次搜索预算已用尽而结束。此解释需要新版本或消融验证；不能只凭本表断言修正后一定成功。
建议下一细分先设计区分“回到接触区域”和“超越历史受阻深度”的条件；仍只用可测相对位移、力和接触历史，不能直接读取真实孔中心。然后用新版本保留对照，不能覆盖本轮。
