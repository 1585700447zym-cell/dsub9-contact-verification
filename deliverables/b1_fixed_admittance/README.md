# B1 固定导纳开发基线

截至 2026-09-16，7 个固定开发工况的 14 个配对回合已完成。两种方法均仅同轴无接触工况满足几何完成条件；其余工况未完成插入。B1 在部分倾角与联合偏差下改善推进，单独横向偏差仍在约 0.25 mm 受阻。

## 查看顺序

1. `B1固定导纳_开发报告.md`：方法、全部结果、限制和判据。
2. `01_B1与零反馈对照.png`：预定联合 A 工况的推进、载荷与姿态。
3. `02_全部工况推进对比.png`：全部工况结果，保留失败。
4. `replay/B1联合偏差_真实轨迹回放.gif`：实际积分记录的局部回放。
5. `../monthly_progress/2026-09/`：6 页可编辑月报、逐页图片和讲稿。

`results_index.json` 是本轮正式索引，`runs/` 保存全部回合。`pilot/` 与 `pilot_index.json` 仅为早期预试验，不纳入本轮正式计数。`configuration_review.json` 保留进入 B1 前的限定诊断。

## 下一步细分任务

| 顺序 | 要做的事 | 本项完成后应拿到的证据 |
|---|---|---|
| B2-1 | 复查 B1 停滞时的局部接触和可用反馈，区分姿态未修正与平面台阶受阻 | 选定一个代表停滞工况，给出接触截图、载荷方向和判断依据 |
| B2-2 | 固定最小搜索与恢复规则，定义搜索范围、速度、超时、回撤和重试预算 | 一页流程及明确的终止条件，保留原保护 |
| B2-3 | 先在一个工况接入搜索，确认动作由反馈与自身运动生成 | 实际轨迹、动作阶段记录和保护检查 |
| B2-4 | 在同一批开发工况比较 B1 与 B2，保留每次失败 | 配对对照表、过程曲线及真实回放 |
| B2-5 | 根据开发结果冻结训练环境接口，再划分独立测试集 | 明确观测、动作、奖励、结束条件和测试范围 |

推进 B2-1 暂不需要完整 CR5 或最终真实夹持位置。现阶段的简化刚性夹持和质量惯量仍需标注为假设；开展实物对应和迁移验证前，必须补充安装变换、负载与接触标定。

## 复现

从工作树根目录执行：

```text
python -m tools.validation.run_b1_baseline --resume
python -m tools.reporting.report_b1
python -m tools.visualization.replay_b1
```

若源码或历史输入变化，恢复运行会拒绝旧检查点，应另建实验输出而不是混用。图表来自记录数据，回放选择保存的真实位姿，不重造运动。月报曲线为稀疏展示采样，完整数值保留在回合 JSON。

## 结论边界

局部推进改善、几何完成、真实插装和电连接是不同证据。本轮未验证总体成功率、传感器噪声、实机安全或学习算法创新。之前动态开发门槛的未通过记录保留，不能因为 B1 已跑通就视为所有接触工况稳定。
