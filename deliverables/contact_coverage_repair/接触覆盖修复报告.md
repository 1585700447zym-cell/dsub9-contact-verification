# 接触覆盖修复：开发模型验证记录

结论：**COVERAGE_GATE_PASS**。此结论只评价本次离散采样中的接触覆盖，尚未验证动态控制稳定性和实物力学精度。

## 为什么先做这一步

原解析SDF在部分明确发生几何交叠的针孔姿态中不生成接触，控制器因而可能看不到本应存在的碰撞。直接开始导纳或强化学习会把检测缺陷混入控制结果。

本次保留原模型和历史报告，新增独立的128段凸分块孔模型。圆孔由内切面包围的多边形逼近：主孔最大径向放大量0.173231μm，入口最大0.203359μm；外轮廓也有相应离散误差。入口仍为阶梯沉孔，没有改成倒角。针、D形外壳、质量、摩擦和接触响应参数沿用原模型；凸碰撞距离容差设为1nm，接触margin保持0。

这是一条替代碰撞建模路径，不能表述为“解析SDF算法已修复”。增大SDF初始搜索点从40到1000虽然减少部分遗漏，但出现容量错误，未通过本次门槛。

## 结果

| 模型 | 重点姿态数 | 成功计算但漏接触 | 仿真错误 |
|---|---:|---:|---:|
| sdf40 | 140 | 17 | 0 |
| sdf200 | 140 | 3 | 0 |
| sdf500 | 140 | 2 | 2 |
| sdf1000 | 140 | 0 | 4 |
| polygon32_original | 140 | 0 | 0 |
| convex64 | 140 | 0 | 0 |
| convex128 | 140 | 0 | 0 |
| convex256 | 140 | 0 | 0 |

128段模型进一步检查了94个工况、11254个姿态：漏接触姿态0个，仿真错误0个，非有限数值0个。其中2517个姿态具有超过1μm的独立交叠见证，2737个姿态产生接触，不能将全部姿态数当作有效碰撞样本数。工况包括原工况、组合误差拆解、±25μm/±0.5°开发域角点和随机点，以及额外32个固定种子20260915随机点。额外随机点对应的3872个姿态中有0个产生接触；若没有接触，仅表示检查了自由间隙内姿态，对碰撞检出能力不增加证据。全程深度间隔50μm，入口前0.5mm加密到10μm。分离工况只检查其原始位置。

重点140姿态复用上一版高密度表面见证；新增密集扫描每根针使用48个圆周方向、33个轴向位置及两端面各9层半径。将针表面点代入独立的解析实体距离函数，交叠超过1μm时必须出现对应针孔接触。1μm只是检验报告门槛，不是实物损伤阈值。采样发现交叠可证明发生了交叠；没有发现不能证明整个连续空间无交叠。本次只检查对应针孔，未认证整个D形外壳的几何间隙。

128段与256段在140个重点姿态均检出预期接触，但接触点数不同。对至少一模型合力超过0.001N的24个姿态，合力向量差除以两者较大模长，中位数为1.9%、最大为8.0%；最大绝对合力向量差0.000514353N。这些是未标定参数下的静态求解结果，不能当作实测插入力，也不能凭接触覆盖通过宣称力已收敛。

所有扫描直接规定位姿并清零速度。超出原30μm阈值后继续推进仅用于暴露漏检，绝不是允许机器人继续插入的策略。“最大穿透”指接触算法返回的最负距离幅值；独立几何见证是另一种量，二者不应混用。

## 计算成本与历史保留

128段的140姿态检查耗时0.540s；密集扫描（含独立几何见证）耗时98.5s。计时包含数据分配、接触力提取，不含编译；并发工作、CPU负载会影响结果。这不是GPU训练吞吐或动态仿真速度承诺。

运行前后比对715项历史输入SHA-256，全部保持一致。导出的XML已实际重新加载并用于验证，依赖同一项目原始assets和models目录，不能单独复制XML当成完整模型。

## 紧接着做什么

1. 使用本开发模型建立动态笛卡尔执行器：明确位置与速度限制、控制周期、观测坐标系，以及力矩从配合原点到工具参考点的转换。先做无接触跟踪，再做低速单方向接触与撤退。
2. 验证接触力方向、能量与数值稳定性，并对128/256段、时间步和接触参数作动态敏感性检查。发生超限、非有限状态或异常速度时终止该回合，记录失败原因。
3. 通过上述检查后实现B1固定导纳，再做B2搜索恢复，随后才进入残差强化学习。用户提供的训练设备为4060和5070Ti，目前尚无吞吐和显存需求实测，不能据此承诺训练速度或论文录用。

现在无需等待真实夹持位置便可进行简化刚性夹持的数值开发。实际夹持位置、工具长度、负载惯量、传感器安装方向与标定、夹爪柔顺性需要在实机迁移前测定；当前暂定工具点不能写成已经标定。也不应把未来CR5整体模型的接入等同于完成实机验证。
