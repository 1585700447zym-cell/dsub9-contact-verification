# 工程链路范围与姿态参数记录 v1

2026-09-26。本记录补齐训练合同v3要求的参数依据，不修改合同、模型、控制器、动作、奖励或保护阈值。是否实际准入，以本次完整检查结果为准；本文存在本身不构成准入。

## 判定与用途

仅固定首次工程链路试训的运行参数：XY各独立均匀分布于±50μm，初始roll=pitch=0，Z起点−4mm、目标推进4mm；原四维残差幅度、2ms策略/控制周期、0.2ms物理步不变。用途是检查采集—学习—保存—加载—评价链路，不是接触纠偏收益或实物适用性认证。

`max_rotation_from_start_rad=0.04363323129985824`（2.5°）固定为相对初始实际姿态的**检测/停止触发值**。使用四元数最短SO(3)转角，每个物理子步检查；不是绝对欧拉角逐轴界限，不是硬饱和，更不是“角度以内模型必然可信”的断言。初始守卫保留原1.5°候选检查，但本次可生成/接纳的初始角度仍严格为零，不能把该守卫允许值当作训练分布。

## 越界、无效与停止处置

仍联合使用原0.025N力、0.0005N·m力矩、30μm穿透停止、80μm严重穿透无效及全部原运动/数值守卫；实际参数由环境实例核对。任何角度内外都不能跳过这些规则。2.5°事件触发物理停止，保留超调及后续全部事件；停止不合格、数值无效或严重穿透均隔离整回合。有限正常/保护/运动失败是否可学习，须由B.2正式适配在此限定前提和全回合实际停止审核下裁决，不能直接翻转旧候选会话的false标志。

同一有限工况重复无效/停止不合格，或某类策略动作反复造成丢弃时，停止扩大训练并检查平台，不静默重采样。B.2必须把范围检查、准入文件摘要和当前源码/环境/配置复核接入采集入口；缺项即拒绝。该要求是合同已有规则，并非新的可调失败门槛。
