# 普通四维残差 SAC 训练合同 v3

修订日期：2026-09-23。状态：**设计依据，尚未实现或验收；training_admitted=false。** 本合同补充并替代v2作为新接口的实现依据，不改变v2与历史结果的归档含义。当前进度见[项目进度跟踪](../../项目进度跟踪.md)，结构见[共用回合管理设计](../superpowers/specs/2026-09-23-residual-session-design.md)。

## 1 保留的环境与任务定义

独立MuJoCo 3.13.0，显式核对包路径及DLL指纹；native、256段、ccd_tolerance=1e-12；物理步0.2ms，控制步2ms。正式3.9.0及旧SDF路径保留。初始化时不允许静默换包、换后端或采用默认128段。

冻结原B2作基线，B1作简单对照；共用几何、驱动、总动作限制、保护和完成标准。六维接触反馈为仿真 `simulation_contact_wrench`，不是已标定FT传感器。SI单位，参考点M，任务轴与世界轴重合。

动作预算20s，任务最终观察沿用原1s上限及提前结束规则。完整成功同时满足原FINISH深度、XY、姿态、速度、载荷与连续保持条件。停止后安全审核覆盖真实最终STOPPING起点后的2s，并核查原规定的连续稳定窗口及记录末端；不追加成功机会。

## 2 共用周期与策略时间尺度

物理、基线控制、策略决策是三个明确配置项。首版兼容配置使用策略周期2ms，先确保零残差逐周期一致；不能把策略频率隐含在训练库默认值中。

周期顺序：读取物理状态和事件 → 执行原回合的预算/恢复前置逻辑 → 必要时恰好更新一次基线并缓存本周期命令 → 构造策略观测 → 合成残差与共同限制 → 积分10个物理子步 → 更新事件、奖励、任务结果及下一周期缓存。观察、记录和渲染只能读取，不得额外更新基线。非活动阶段不为凑“每周期一次”而强行调用基线。

首版折扣明确采用连续时间常数的工程初值：`discount_time_constant_s=10`，`gamma=exp(-0.002/10)`，约0.99980002；这是可调工程起点，不是已验证最优参数。训练配置保存公式、实际数值及版本。禁止直接沿用0.99而不核查其秒级意义。

在B.1测量后，可登记策略周期20ms作为单变量候选。候选中基线仍每2ms更新、守卫每个物理子步执行；策略残差在合法阶段保持，停止/回撤发生时立即屏蔽。每个策略转移累计其所有控制步奖励，并使用与实际转移时间匹配的折扣；记录实际Δt。该候选不自动替代2ms首版，必须通过相同零残差、事件、奖励和时间预算检查。普通SAC与后续方法使用相同最终周期。

训练配置必须显式保存学习率、批量、预热、经验池、更新/采样比、熵系数初值与目标熵、种子、网络和库版本。学习参数依据开发测量冻结；未填写或不能复现的配置拒绝训练。

## 3 观测和内部状态

沿用v2字段：M点六维接触力矩的最近四个控制采样、相对起点位移/旋转向量、世界线/角速度、最大已达推进、基线命令、上周期实际受限命令和残差、基线/物理阶段、待结束标记、回撤状态、剩余预算、导纳速度和累计修正、螺旋相位、相对起点搜索原点与受阻历史信息。reset时历史以首观测填充，完全清除前回合状态。

同时显式审查对下一步有影响的已知状态：阶段经过时间、受阻窗口进展及跨度、成功保持计时、停止/恢复等待计时、已锁存原因、参考位姿相对当前位姿的偏差。建立字段表，标注来源、单位、可观测性、归一化尺度及有效位；无定义项使用数值加有效位。

四个2ms采样的首尾跨度仅6ms，不能声称替代B2的0.4s历史或使接触任务严格马尔可夫。首版不增加历史网络；通过显式控制器已知状态减少隐藏状态，仍保留部分可观测任务的结论边界。

归一化尺度继续使用力0.025N、力矩0.0005N·m、平移0.004m、转角0.08rad、线速度0.001m/s、角速度0.03rad/s、相应时间预算；必要时裁剪至[-10,10]。原始值独立保存，守卫不用裁剪值。

真实孔中心误差、初始误差标签、针孔配对、接触点和穿透只进入 `privileged_evaluation`、奖励或仿真守卫；不得通过绝对目标位置、字段排序或辅助特征间接进入策略。当前不添加噪声/延迟/随机化；后续独立版本化。

## 4 动作和安全权限

四维动作在[-1,1]，映射为 `[0.00015*ax, 0.00015*ay, 0, 0.005*ar, 0.005*ap, 0]`，单位m/s、rad/s。仅INSERT/SEARCH且物理RUNNING、无待终止或锁存故障时生效。

UNLOAD、WAIT_RECOVERY、STOPPING、RETRACT、FAILED、TERMINAL均屏蔽残差。按本周期基线更新后的实际阶段选择掩码；一次策略保持期间若阶段改变，也必须重新检查。恢复次数和总时间仍沿用原规则。

合成后INSERT的XY各分量≤0.0005m/s、SEARCH≤0.0003m/s，roll/pitch≤0.02rad/s，再经过共同环境速度/加速度、参考误差、驱动力、实际运动及接触保护。B3/B4共享最大预算，后者只能收紧。

日志分别保存策略归一化动作、请求残差、阶段掩码、阶段限制后总命令、环境受限命令与实际运动。以相同基线及前一受限命令计算零残差的命令限制对照，记录“残差在命令层的有效改变量”和连续裁剪时长；它不是未经对照的物理因果效果。不得仅凭非零网络输出声称策略已有效控制。

新增实际累计姿态守卫作为共同能力。`max_rotation_from_start_rad`必须显式配置，按实际四元数相对回合起点的旋转角检查；初始姿态也必须属于已审查范围。**本次不虚构可用阈值；训练前必须有独立参数冻结记录，给出几何/模型适用范围、基线轨迹包络、候选边界检查、处置规则和共同对照影响。** 0.08rad归一化尺度、±1.5°初始化范围、参考误差限幅均不能自动用作此阈值。缺少记录时拒绝准入。

新共同守卫若改变已有基线轨迹/终止，先形成新共同版本并重评受影响B1/B2；历史七工况结果保留，不能直接与新学习方法跨版本比较。

## 5 数值有效性和结果裁决

每个回合分别记录 `simulation_valid`、`task_outcome`、`guard_violations`、`physical_stopped`、`valid_for_learning`，不压缩成单一失败码。原始事件全留存。

| 情形 | 判读与处理 |
|---|---|
| NaN/Inf、引擎异常、严重非物理穿透、无效输入/初始化 | 数值/数据无效；归档明确非有限标记，整回合不入池 |
| 有限状态中的接触保护超限 | 保护失败；先停止及审核，不因“触发了保护”自动判数值无效 |
| 有限且仍在模型可信范围内的实际速度/行程/姿态违规 | 物理越界失败；执行停止，是否入池取决于回合有效性和尾段审核 |
| 越界同时已超出模型数值可信范围或不能完成可信停止 | 保留物理违规原因，同时判不可学习；不能简单重命名成有效失败 |
| 完整成功 | 必须无更高优先级故障，任务窗口满足FINISH，且安全审核合格 |
| 有效受阻/任务预算耗尽 | 正常任务失败；经过尾段审核后可进入经验池 |

最终原因优先级：无效仿真/命令/初始化 > 接触保护 > 实际运动越界 > 完整成功 > 有效受阻/预算失败。先收集同一物理子步的全部事实再裁决，不能因先检查位移就漏掉同时发生的接触超限。

STOPPING期间继续统计和锁存首次及后续接触违规，不重启停止计时。物理停止与任务完成分别记录；停止不合格不得宣称安全成功。原 `OUT_OF_BOUNDS` 分类属于旧版本，不能直接作为新学习数据分类器。

## 6 奖励和经验动作语义

首版沿用v2奖励：`5*新增最大推进/目标行程 - 0.1*Δt - 0.2*Δt*(F/0.025)^2 - 0.2*Δt*(T_G/0.0005)^2`。目标行程从初始化目标计算；最大推进裁剪到[0,目标行程]，往返不重复增加。

F/T为本控制周期物理子步峰值。分别维护周期峰值和回合累计峰值，周期开始清零前者，不能用累计峰值做差推算。终末唯一奖励：完整成功+10，有效过载/越界−10，其他有效任务失败−2。时间成本包含任务停止观察及安全尾段；不因静止等待获得正奖励。

保留各分项、实际Δt和唯一终末奖励标记。原规划要求关注平滑性：首版通过共同变化率限制并报告平滑性指标；本版本不另加未经验证的平滑性奖励项。增加该项属于奖励版本变更，先用开发/验证反例审查并记录。

经验中的动作使用四维归一化策略请求，阶段无权限时规范为零；六维最终执行命令另存，不能把二者混用。阶段有效标记进入观测/经验。无残差权限状态不参与actor和温度更新，critic仍按真实转移学习；下一状态无权限时，目标不附加虚构的动作熵收益。熵系数和奖励尺度配套核查，不能因停止尾段增加大量无效动作而改变比较口径。

## 7 整回合审核和截断

所有转移先进入回合暂存区，完成有效性与停止审核后才一次性提交经验池；无效回合整段隔离，NaN/Inf不传入学习更新。有效任务和合格的保护失败均保留。所有尝试进入评价分母，同时报告有效样本条件下指标、丢弃率和原因。

若同一有限工况可重复触发数值无效/停止不合格，或某类策略动作反复使经验被丢弃，停止扩大训练并检查共同平台；不得通过重采样或删除困难回合掩盖问题。

20s任务预算耗尽是 `terminated=true`；正常训练批次结束不是回合结束。首版训练停止请求优先等当前完整回合审核完成，报告实际超出目标的步数。真实外部截断才使用 `truncated=true`，二者互斥。

真实外部截断必须保存截断时的真实下一观测，不能使用reset后的观测。截断后可做独立安全收尾审核，但不得将安全收尾状态替换为bootstrap状态，也不得补造任务超时/成功终末奖励。收尾无效则整个暂存回合不入池；收尾合格才提交截止截断点的转移。变周期转移使用对应Δt折扣。

## 8 训练范围与数据使用

工程链路范围保持XY各±50μm、roll=pitch=0、Z起点−4mm；四维动作仍可能产生倾角和接触，不能因此免除姿态/接触守卫。其作用是检查训练链路，不预设纠偏收益。

名义径向间隙75μm，工程范围最大合成偏差约70.7μm，而FINISH的XY误差要求≤50μm。本轮225静态样点均无接触；不是连续域或动态证明。无接触且未主动探测时，相对起点运动与零力反馈可能不能区分初始误差。奖励使用真值不等于策略获得该信息。

进入接触学习前单独登记开发分布：在原预设扩展范围XY各±100μm、roll/pitch各±1.5°内，先位置接触、再姿态和联合误差。每一层做初始化、接触信号、动作有效作用、动态稳定和停止/恢复预检；记录失败与不可观测区域，不声称验证整个连续域。主动探测或增加可部署测量会改变任务设计，须先说明方案和证据；不直接加入孔真值。

原[数据划分v1](../../deliverables/baseline_training_readiness/数据划分_v1.json)保持冻结。七工况及旧探针始终开发用途。验证集用于调整；独立测试仅在方法与检查点冻结后使用，并登记首次使用、范围和目的。B.2独立评价后，该子集不再是后续方法调试可复用的“未见测试”；正式研究若需新最终测试，先登记而不据已有结果挑选。

## 9 实际准入与交付

B.1必须实际通过以下门：

- 环境路径/DLL/配置指纹与依赖隔离；读取/渲染幂等及reset隔离。
- 历史B2零残差逐周期比较；新共同保护启用后，与同版本B2的零残差比较。不得只比较深度。
- 四轴方向/尺度、所有阶段掩码、总命令与变化率、真实姿态边界。
- 周期峰值、任务/尾段计时、同周期保护优先级、唯一成功奖励、静止/往返反例。
- 数值无效与有限物理失败、整回合隔离、外部截断和正确bootstrap。
- 恢复成功、实际回撤不足、恢复拒绝/超时、保护锁存和全过程残差屏蔽。参考位移达标不等于实际回撤达标。
- 初始化与代表动态范围预检、残差有效作用统计、无界面吞吐及采样/更新成本。
- 未训练策略或确定性测试策略保存加载一致；该项不算已交付训练权重。

B.1通过才开启B.2短训。B.2另交付训练策略、重复运行、固定评价和冻结后独立评价；工程短训完成不得提前标原任务6已验收。每项可交付阶段结束更新[进度跟踪](../../项目进度跟踪.md)、月报和证据链接。
