## 1. 本次实现范围

- 在原残差SAC路径上增加yaw，动作顺序为X、Y、roll、pitch、yaw，输出的是速度残差。
- 保留450 μm/s传统螺旋搜索、Z轴力控、N2、固定导纳及被动Mz→yaw通道。
- 在INSERT和SEARCH两个合法阶段使用残差；卸载、恢复、等待、停稳及终止阶段关闭残差。
- 保留原四帧、跨度6 ms的短时力觉；只增加必要的yaw控制器状态。
- 实现普通双Q SAC、整回合审核回放、完整学习组件保存恢复、失败证据采集。

本版没有新增长历史、接触分类器、门控、搜索暂停、GRU、模仿学习、主动yaw扫描或新的奖励项。搜索仍由原螺旋产生基准路线，SAC在其上修正五维速度。

## 3. 动作与共同边界

输入动作每维为有限的[-1,1]数值。映射到世界坐标六维速度中的索引0、1、3、4、5；Z残差恒为0。

| 动作维度 | 归一化动作为±1时的残差 |
|---|---:|
| X | ±0.00005 m/s，即±50 μm/s |
| Y | ±0.00005 m/s，即±50 μm/s |
| roll | ±0.0005 rad/s |
| pitch | ±0.0005 rad/s |
| yaw | ±0.0005 rad/s |

合成后的阶段限幅：INSERT的X/Y每轴±0.0005 m/s，SEARCH每轴±0.00045 m/s，三个角向分量各±0.02 rad/s。实际执行还经过共同驱动速度／加速度限幅：线速度0.001 m/s、角速度0.03 rad/s、线加速度0.005 m/s²、角加速度0.3 rad/s²。

本版SEARCH没有沿用旧四维合成器的300 μm/s上限。零残差保留当前450 μm/s基准命令；这不表示任何时刻都能达到450 μm/s，驱动加速度、阶段切换和参考范围仍可能限制执行。

搜索参考继续使用半径0.4 mm共同范围：比较同一前次执行状态下的零残差与带残差候选，必要时缩小两者之间的修正。零残差也无法留在范围内时，记录`RESIDUAL_REFERENCE_INFEASIBLE`并进入原失败／停止流程。记录请求残差、阶段限幅、参考过滤比例及最终有效命令差，避免把饱和动作误认为全部生效。

N2搜索目标力2 N、5 N／0.1 N·m保护、25 s任务时限和相对起点2.5°保护复用当前基线；yaw导纳惯量0.02、阻尼1、速度上限0.02 rad/s、累计偏移上限0.08 rad。

## 4. 140维观测

原137个输入分量保留次序，含原四帧六维力觉、相对起点运动、控制器／恢复状态、预算、基准和前次执行命令、四维前次残差、参考误差和参考过滤状态。本版力觉按N2的5 N／0.1 N·m重新归一化。

| 新字段 | 零起始索引 | 原始单位 | 归一化尺度 |
|---|---:|---|---:|
| `previous_yaw_residual` | 137 | rad/s | 0.03 |
| `yaw_admittance_velocity` | 138 | rad/s | 0.03 |
| `yaw_admittance_offset` | 139 | rad | 0.08 |

`previous_yaw_residual`表示前次经阶段权限掩码的物理yaw残差请求；实际饱和／参考过滤后的效果另见动作日志。新增三项是当前控制器状态，不是阶段B的长时接触、动作或实际运动历史。

不向策略提供逐针孔配合真值、真实公母头中心误差或成功标签。仿真真值沿用原评价记录用途。相对起点运动不等于已知真实孔位误差。

## 5. 普通SAC、回放和终止

默认设置：actor／critic学习率0.0003，双隐藏层256/256，batch256，回放116000，初始温度0.01，目标熵−5，软更新系数0.005，CPU单Torch线程，随机种子2026092716。warmup和回放抽样各有独立随机流。

实际时间折扣为`exp(-dt/10 s)`。采用普通双Q SAC，不加入旧试验的边界重采样或精确尾段目标。

- 当前动作禁用时执行并保存零五维经验动作，该行不计入actor和温度损失；全批禁用时跳过actor及温度更新，包括Adam动量更新。
- 下个状态禁用动作时，目标动作是零五维，不加入策略熵项。
- 终止行不能宣称下个状态仍允许动作。
- 整回合发布审核140／5、权限、时间折扣、连续性和终止边界；不逐行发布半个回合。
- 外部审核通过前，采集结果始终`training_admitted=False`、`valid_for_learning=False`。采集完成不等于允许入池。

## 6. 失败、成本与完整保存恢复

采集器保留控制行、动作与奖励、载荷所在轨迹、周期峰值和完整环境／控制器事件，并独立复制停稳子步、保护事实、接口故障、当前观察、停止／任务结束／审核结束时刻。当前观察失败时记录诊断错误；历史`last_finite`单独标记，不代替当前真值。

策略回调前累计尝试数；返回并通过五维动作校验后才累计成功数。推断失败时也记录policy调用；warmup抽样单列。记录初始化尝试／完成、实际物理子步和墙钟耗时。中途子步不能用完整控制周期数推算。reset失败后本次子步不能可靠确认时记未知，避免使用上一个回合的计数。

保存恢复仅允许健康、完整回合／完整更新边界，覆盖actor、双Q、目标网络、全部Adam状态、温度、回放、抽样随机流、Torch随机流、计数和诊断历史。文件带版本、摘要及配置核对，写入新目录，不覆盖既有检查点。恢复先完整校验候选，再替换内存状态；旧四维或缺字段检查点拒绝载入。

**边界：**这不是MuJoCo中途状态恢复，也尚未与真实运行来源凭据、训练准入凭据绑定。不声称已验证断电／进程崩溃恢复。
