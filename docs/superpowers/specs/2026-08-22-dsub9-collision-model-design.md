# D-sub9 坐标规范与 MuJoCo 碰撞模型设计

## 1. 目标

为 D-sub9 精密插接建立可复现的视觉资产和碰撞模型，支持后续直接插入、导纳控制、接触状态识别与残差强化学习。模型必须保留 D 形外壳导向以及 9 组针—孔多点接触，能够表达横向偏差、姿态偏差、卡滞和相应六维接触载荷。

本设计不拟合真实连接器簧片的材料弹性和绝对插入力曲线。几何接触验证通过后，再增加独立、可随机化的轴向等效阻力模型。

## 2. 已核实的源模型

源文件位于 `DSub9_Deliverables_V4/`。

### 2.1 母头

- STEP 顶点范围：X = [-15.4, 15.4] mm，Y = [-6.275, 6.275] mm，Z = [0, 9.7] mm。
- STEP 尺寸：30.8 x 12.55 x 9.7 mm。
- STEP 的装配坐标正确：原点位于插入口中心，+Z 指向孔内。
- 现有 STL 尺寸正确，但范围为 X = [0, 30.8] mm，Y = [0, 12.55] mm，Z = [0, 9.7] mm；导出时未使用装配坐标系。
- 现有 STL 需要平移 (-15.4, -6.275, 0) mm，且不得缩放或旋转。

### 2.2 公头

- STEP 顶点范围：X = [-15.4, 15.4] mm，Y = [-7, 7] mm，Z = [-22, 4] mm。
- STEP 尺寸：30.8 x 14 x 26 mm。
- STEP 已以 `CS_MATE_MALE` 居中，+Z 指向针尖和插入方向。
- 当前没有公头 STL，需要从 STEP 按该坐标直接三角化导出。

### 2.3 统一装配约定

- CAD/STL 检查和报告使用毫米。
- MJCF 使用米，导入 STL 时统一应用 0.001 比例。
- 母头坐标系为任务参考系。
- 公头从母头负 Z 侧沿 +Z 接近。
- 理想完全插入时公、母装配坐标原点重合；公头针范围 Z = [0, 4.0] mm，母孔有效深度 4.5 mm。

## 3. 碰撞表示

### 3.1 视觉模型与碰撞模型分离

- 修正后的完整公、母头 STL 仅用于显示，`contype=0`、`conaffinity=0`。
- 所有接触均由独立碰撞几何产生。
- 后壳、法兰和固定结构只保留影响初始干涉或安全边界的粗略碰撞体，不参与针孔精密配合。

### 3.2 公头碰撞几何

- 9 根针使用 MuJoCo 解析圆柱，直径 1.00 mm、长度 4.00 mm，保持 5+4 排列。
- 横向中心距 2.77 mm，两排中心距 2.84 mm。
- 针轴与 +Z 一致，针根位于 Z = 0，针尖位于 Z = 4.00 mm。
- D 形导向壳按 CAD 截面拆成少量互不填孔的凸棱柱；保留两侧斜边、上下导向边和入口主要圆角。
- 公头后壳和法兰使用盒体或少量凸体，仅用于防止非任务区域穿透。

### 3.3 母头圆孔碰撞几何

- 正式模型使用 MuJoCo 3.x 解析 SDF，不使用 12 至 16 边多边形作为主模型。
- 每个母孔由有限长度的空心圆孔 SDF 表示，内径 1.15 mm、有效深度 4.50 mm。
- 入口导入段按参数说明表示为直径 1.35 mm、深度 0.25 mm 的同轴圆形扩孔。
- 9 个 SDF 孔严格复用公头的 5+4 阵列中心；孔轴与 +Z 一致。
- SDF 只描述针附近的局部孔壁，局部外半径小于相邻孔中心距的一半，避免相邻局部壁体重叠和重复接触。
- 母头 D 形插座内壁按 CAD 截面拆成凸棱柱，保留入口导向面及对偏斜最敏感的边缘。

### 3.4 性能回退模型

- 同时生成 32 边圆孔代理，仅用于 SDF 性能或稳定性对照，不作为论文主模型。
- 半径 0.575 mm 时，32 边圆孔的最大径向离散误差约 0.0028 mm；报告中必须明确它相对于 0.075 mm 名义径向间隙的比例。
- 只有当 SDF 无法满足稳定性或批量仿真速度要求时，才允许切换到回退模型，并保留两种表示的对照测试。

## 4. SDF 实现边界

- 使用 MuJoCo 3.x SDF 插件接口实现解析距离和梯度，不依赖体素化 STL 解析孔壁。
- 单孔距离函数必须包含有限轴向范围、1.15 mm 主孔和 1.35 mm 入口扩孔。
- 距离函数在主孔、入口扩孔和端面交界处采用连续的 CSG 组合；梯度方向必须指向最近实体表面。
- SDF 资产必须能被标准 MuJoCo CPU 仿真加载；第一阶段不要求 MJX 支持。
- 插件构建方法、MuJoCo 版本和平台限制必须写入运行说明。

## 5. 接触物理边界

- 针、孔壁和 D 形导向件按刚性体处理，柔顺性由 MuJoCo 接触参数表达。
- 初始模型只要求接触力和力矩的方向、相对大小及卡滞趋势合理，不声称绝对牛顿值与实物一致。
- 名义针孔径向间隙为 0.075 mm。接触 `margin`、允许穿透量和数值公差必须显著小于该间隙，不能因接触膨胀造成理想对准时的虚假碰撞。
- 未标定的摩擦、接触刚度和阻尼必须放入版本化配置，并在验证阶段进行参数敏感性测试。
- 正常对准时真实簧片造成的轴向阻力不由圆孔侧壁伪造；后续用独立等效阻力模块表达。

## 7. 验收标准

### 7.1 几何与坐标

1. 修正后的母头视觉 STL 包围盒为 30.8 x 12.55 x 9.7 mm，X/Y 关于零对称，Z 从 0 开始。
2. 公头视觉 STL 包围盒为 30.8 x 14 x 26 mm，范围与公头 STEP 一致。
3. 公、母头在统一装配坐标下孔位与针位逐一同轴。
4. 所有输出 STL 为有效三角网格；碰撞分块闭合且方向一致。

### 7.2 接触行为

1. 分离状态无虚假接触。
2. 理想对准能够以准静态方式进入 9 个孔，且针孔侧壁不产生持续虚假载荷。
3. 横向偏差产生方向合理的侧向力，并随偏差增大出现更多针孔接触。
4. 倾斜偏差产生方向合理的接触力矩。
5. 联合偏差能够形成多点接触、卡滞或安全终止条件。
6. 明显碰撞不得穿透 D 形导向壁或孔壁。
7. 静止接触载荷不持续发散，不出现 NaN 或 Inf。
8. 时间步减半后，成功/卡滞判断和主要受力方向不得反转。

### 7.3 SDF 与回退模型对照

1. 两种模型的理想插入结论一致。
2. 在固定横向和倾斜扰动下，两种模型的接触方向与主要卡滞模式一致。
3. 记录单步计算时间、接触数量和批量运行稳定性。
4. 若正式采用回退模型，必须报告几何离散误差及其对成功边界的敏感性。

## 8. 明确不在本任务内的内容

- 真实簧片形状、材料非线性、塑性损伤和磨损。
- 实物插入力—位移曲线辨识。
- 机器人本体、夹爪、导纳控制器、强化学习环境和奖励函数。
- 根据仿真直接给出真实机器人安全力阈值。

这些内容应在碰撞几何通过验收后分别进入接触参数、控制基线和实机安全任务。
