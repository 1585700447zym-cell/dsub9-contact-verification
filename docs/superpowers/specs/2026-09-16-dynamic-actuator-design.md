# 动态笛卡尔执行器：设计与本轮范围

用户在讨论128/256段动态比较及联合初始误差后于2026-09-16授权继续。实现此前闭环接口协议的动态底层子集；本轮不实现B1、B2、SAC及实机驱动。

公头保留自由刚体、质量0.05kg、关于M的各向同性惯量2e-5 kg m²；母头固定，重力0。几何来自独立凸分块生成器，原文件保持不变。G=M+(0,0,-0.0145)m为刚性夹持假设，非标定参数。测量为接触合力与关于G的力矩，不冒充串联传感器完整读数。

受限笛卡尔PD驱动作用于M；将等效力矩转换至G后通过mj_applyFT施加于刚体。目标位置与四元数积分，只有reset写实际qpos；step以mj_step推进。实际速度受力决定；参考速度、加速度、跟踪误差及驱动力均有界。保持当前模型低质量用于数值开发，不能代表CR5等效惯量。

物理步长比较0.0001/0.0002/0.0004s，控制周期0.002s。每物理子步更新驱动力并检查有限值、MuJoCo警告、载荷、穿透、实际速度和工作域。过载时取消推进、冻结参考到当前位姿并用有限阻尼减速；严重新数值异常立即终止，不能强行回撤。停止后仅在有限状态、恢复允许载荷、速度已小、回撤预算未耗尽时允许有限回撤。保护不保证峰值永不越限。

接口：DynamicConfig；CartesianEnvironment(config, segments=128, contacts_enabled=True)；reset(ContactCase)；step(command_world_6)；stop(reason)；request_recovery()；observe()。step返回记录，不伪装已完成Gym/SAC环境。命令为M处世界坐标线/角速度。已知真实误差与穿透只用于验证，不默认为策略观测。原始命令、限幅命令、驱动饱和与接触峰值单独记录。

实验：同轴自由运动、六轴响应、停止和有条件回撤、侧向碰壁、半幅/四分之三幅联合A/B、原组合压力工况。配对无接触模型仅作为反事实检查接触是否改变轨迹；不能用于证明装配成功。128与256段以及三时间步使用相同工况/控制/参数。保留失败，验收指标提前固定：自由跟踪终点误差<50μm；停止0.2s内速度<10μm/s；数值有限、驱动限幅成立；至少一个接触实验相对关闭接触有>2μm轨迹差或>0.01°姿态差；时间步/分块比较终止原因一致且末端位置差<20μm、姿态差<0.1°，有效力>0.001N时峰值力相对差<20%。这仅为开发数值一致性门槛。
