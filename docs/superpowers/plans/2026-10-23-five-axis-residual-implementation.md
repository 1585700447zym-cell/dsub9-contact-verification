# 阶段A五维残差SAC：实施计划与执行记录

**目标：**实现独立的五维残差动作、140维短时观测、N2会话、普通SAC更新、完整回放与保存恢复；保留四维历史接口。

**依据：**[整体路线阶段A](2026-10-23-sac-five-axis-staged-roadmap.md#stage-a)。用户于本轮明确要求继续实现。

**边界：**复用当前yaw初始化、N2、450 μm/s螺旋、Z力控、现有恢复与保护；不加入长历史、门控、搜索暂停、示范或新奖励。当前只实施与离线／合成数值验证，不启动研究物理回合或正式训练。

## 任务与验收

- [x] T1 动作与契约：五维归一化动作映射到六维速度，Z残差为0，SEARCH保留450 μm/s，含共同参考范围过滤；正负yaw与禁用阶段检查。
- [x] T2 观测与会话：复用原137字段，追加前次yaw残差、yaw导纳速度和偏移，共140维；四帧6 ms历史和N2归一化保持，保留原回合生命周期。
- [x] T3 学习与回放：普通双Q SAC、目标熵−5、禁用动作及actor／温度掩码；整回合发布、连续性与时间折扣审核，拒绝四维样本。
- [x] T4 完整保存恢复：模型、目标网络、全部优化器、温度、训练计数、回放与随机流；检查摘要、配置与旧版本拒绝；下一批抽样和更新等价。
- [x] T5 集成检查与交付：独立入口说明与合成检查，相关回归、一次独立审查、文档及进度更新；明确未执行的物理资格与训练。
