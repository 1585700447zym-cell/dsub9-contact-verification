# B.2第3项｜全局残差权限与30秒共同限时实施计划

> 执行者：后续实施时按 superpowers:executing-plans 或 subagent-driven-development 分任务完成。本文件仅为计划；未启动实现、仿真或训练。

**目标：** 保持现有搜索与导纳，先验证扩大五维接口中XY及yaw残差权限后，命令和实际运动是否有可辨认的改变，再决定是否值得开展学习对照。

**结构：** 新增独立残差版本和试验入口，复用原阶段切换、搜索、卸载恢复、动力学与判据。旧尺度与新尺度两组均用30秒任务窗，只比较残差权限组合。

**技术栈：** 现有Python/NumPy控制与N2动力学环境；本阶段不用神经网络或优化器。

**依据：** 用户2026-10-28最新要求“全局只更改残差相关，局部调姿暂且搁置，限时提高到30s”；本计划替代上一版局部调姿窗口计划。参数和验证脚本是本版具体提案，不能表述为已实现或已通过资格。

## 1. 范围与判断边界

- 局部调姿窗口、暂停螺旋、局部触发、被动Mz门控、局部轨迹衔接、局部额外观测均移出本轮。
- 固定锚点、回锚和相关恢复改动继续取消。保留原搜索原点设置/重置、半径0.4 mm、螺距0.1 mm、搜索速度450 μm/s和现有卸载恢复。
- 保留2 ms控制周期、N2动力学、2 N搜索力、5 N/0.1 N·m保护、相对起点2.5°旋转保护及九针三维成功判据。不增加推进力、不改变被动Mz→yaw符号或参数。
- 不添加接触/动作/运动历史，不改变奖励、熵系数、动作保持方式或网络结构；本阶段无新增训练、神经推理和最终测试。
- “全局”是指原本允许残差的SEARCH和INSERT阶段统一采用新尺度，不表示停稳、回撤、恢复或终止阶段也能输出残差。
- 30秒是独立于残差的任务设置变化，因此旧、新两组都使用30秒。旧25秒结果仅作背景，不能直接拿来证明残差收益。
- 本次同时调整XY和yaw权限，是一个残差权限组合对照；不能分别认定哪个轴造成任务结果变化。

## 2. 残差参数与限幅关系

归一化动作仍为5维，顺序为X、Y、roll、pitch、yaw，范围均为[-1,1]。

| 参数 | 对照组G0 | 候选组G1 | 理由 |
|---|---:|---:|---|
| X、Y残差，每轴 | ±50 μm/s | **±500 μm/s** | 使残差有能力明显抵消或改变450 μm/s基线分量 |
| roll、pitch残差，每轴 | ±0.0005 rad/s | ±0.0005 rad/s | 先保留已有倾角调整，避免扩大无证据问题 |
| yaw残差 | ±0.0005 rad/s | **±0.005 rad/s** | 提高主动yaw相对被动Mz响应的影响能力 |
| Z残差 | 无 | 无 | Z继续由原导纳和阶段逻辑负责 |
| 任务时限 | **30 s** | **30 s** | 同期共同条件 |

仅扩大残差请求尺度，以下限制不扩大：

- SEARCH合成XY速度仍逐轴限于±450 μm/s，INSERT为±500 μm/s；合成角速度仍逐轴限于±0.02 rad/s。
- 原驱动速度、加速度、参考前导限制、搜索参考盘和实际运动保护继续执行。
- 例如基线X=+450 μm/s，新残差X=−500 μm/s，阶段限幅前合成为−50 μm/s；同向+500仍会被总速度上限截断。因此不是让公头以950 μm/s搜索，也不能承诺实际运动十倍增长。
- 原搜索盘过滤对六维命令增量共同缩放，XY临近边界可能连带削弱yaw。首轮保留这个机制，记录其贡献；若证据显示它主导丢失，再单独讨论残差分配，不在本轮顺手修改。
- 被动yaw最大角速度0.02 rad/s仍可能超过主动0.005 rad/s。扩大权限不保证任何接触状态下都能反转净yaw；须实测合成命令与实际姿态。

## 3. 30秒的具体定义

1. 从每回合任务起点计时，总任务窗由25秒变为30秒；全生命周期的截止判据、控制配置、观察中的剩余时间、回执和采集上限一致。
2. 原单次搜索18秒上限、搜索次数、恢复次数及半径耗尽条件不变；延长总时限不等于额外增加5秒有效搜索。
3. 原任务后的停稳/审核尾段仍单独保留2秒，单回合采集上限32秒，即16000个2 ms周期，最多160000物理子步。
4. 报告分别列出25秒时的状态与最终30秒内的结果。25秒截面不是新增一回合，也不替代旧版25秒独立对照；状态依赖30秒合同，不能将截面当作严格相同的25秒试验。

## 4. 实现任务与必要检查

### 任务1：独立残差版本与30秒适配

拟新增文件，路径均相对本工作区：

- `tools/learning/global_residual_action.py`：G0/G1尺度、动作映射和合成；复用现有限幅算法，不修改原冻结模块或运行时替换全局常量。
- `tools/learning/global_residual_session.py`：独立会话入口，设置共同30秒，保持原控制工厂/生命周期及观察构造。
- `tests/test_global_residual_authority.py`：与本变更直接相关的纯逻辑检查。

接口约定：动作合成提供`compose_command(base, action, *, profile, phase, enabled, previous_limited, dt, reference_xy=None, radius=.0004)`，返回`(command, log)`；profile只接受已登记G0/G1。会话工厂提供`session_class(profile)`，其构造、reset与逐周期接口沿用旧会话。

- [ ] 先固定G0/G1物理尺度与版本标识，动作维度5、观测维度140保持。取消上一版159维局部观测提案。
- [ ] 完成五轴映射、禁用归零、旧尺度逐项等价、限幅和搜索盘过滤检查；包含非法动作拒绝与每回合状态重置。
- [ ] 完成30秒截止及32秒尾段预算检查；确认18秒搜索预算不随之改变。
- [ ] 零动作下G0/G1命令完全相同；原尺度输入下新合成器与旧合成器一致。正常残差权限与现有观察验证一致。

140维不代表旧模型和数据可无条件续用：原观察中的剩余时间/阶段时间按任务时长归一化，30秒会改变输入语义，动作尺度也改变了归一化动作的物理含义。新版本必须记录尺度与时限；本轮不加载旧检查点、不发布学习回放，后续训练的数据复用另行明确。

### 任务2：一次四回合工程对照

拟新增`tools/validation/run_global_residual_authority.py`，复用既有隔离运行、回执、原始轨迹保存、停稳审核与成本核对模式；执行入口先登记，再显式启动，不在导入时启动。只统计和分析保存轨迹，不附加神经诊断。

| 顺序 | 工况 | G0 | G1 |
|---|---|---|---|
| 第1对 | X/Y=+0.30/+0.30 mm，roll/pitch=−1°/+1°，yaw=+1.5° | 旧尺度，30秒 | 新尺度，30秒 |
| 第2对 | X/Y=+0.30/+0.30 mm，roll/pitch=−1°/+1°，yaw=−1.5° | 旧尺度，30秒 | 新尺度，30秒 |

四回合共用同一归一化诊断脚本，不根据初始yaw符号、真实孔位或逐针状态选动作：

- 首次SEARCH开始0.2秒后，依次请求+yaw、−yaw、+X、−X、+Y、−Y，其他分量为0。
- 每段1秒：0.2秒平滑增至归一化满幅、0.6秒保持、0.2秒降至0；段间0.2秒零请求。按每个2 ms周期更新脚本，未引入训练中的动作保持模块。
- 所有其他时段输出零残差。阶段退出、残差权限中断或保护触发，立即取消剩余脚本，不跨恢复续接或重新补发；未执行部分记为未获得证据。
- 该脚本是测试输入，不是拟部署的局部调姿控制器：不暂停螺旋、不关闭Mz、不重设搜索中心，也不识别孔口。
- 一个候选yaw脉冲请求积分为0.004 rad，约0.229°。它检查双向影响能力，不承担一次纠正完整1.5°的任务。
- 固定先正后负顺序在两个初始yaw工况中的作用不同，只做各工况内G0/G1比较，不把正负工况之间的差异当作方向性结论。平滑输入仍可能因基线变化而触发加速度限制，照实记录。

- [ ] 先执行和审核第一对，再执行第二对；每个工况每组最多一次，不重跑、不补齐中断脚本。
- [ ] 正常超时或有效接触保护失败保留并继续既定下一点；仿真无效、超已资格运动域、来源不符、保存/审核/计数异常停批。
