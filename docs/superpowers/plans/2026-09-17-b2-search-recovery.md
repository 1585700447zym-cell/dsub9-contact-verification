## B2-4 七工况同条件比较

- [x] 先冻结最终开发参数及代码指纹，再重跑相同时限的 B1/B2 配对。
- [x] 保存全部14回合，检查成功条件、连续保持、物理步峰值及采样完整性；失败和无改善均如实报告。
- [x] 输出推进、完成时间、峰值力、回撤次数和终止原因对比，保留月报素材。

结果：两策略均只有同轴工况完整达标；B2的X及联合B×0.75工况深度到位但精度未满足；其余4个接触工况搜索预算耗尽。没有修改冻结控制器。发现回撤后累计推进0.10 mm可能尚未回到历史受阻深度就退出搜索，下一步优先审查此条件，不能直接进入训练并假定基线已验证。
