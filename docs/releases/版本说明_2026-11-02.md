## 当前算法和共同条件

当前保留固定导纳、传统搜索以及五维残差 `x/y/roll/pitch/yaw`，原四轴导纳之外已有独立的 `Mz→yaw` 被动反馈。观测接口为 140 维，动作 5 维；保留现有短历史接口，没有新增接触/动作/实际运动长历史模块。

搜索半径 400μm，传统搜索单轴上限 450μm/s，任务时限 30s；G1 残差满量程 XY 各 500μm/s、roll/pitch 各 0.0005rad/s、yaw 0.005rad/s。控制/网络计算周期仍为 2ms。最近诊断只把随机探索 epsilon 保持 50ms（25 周期）；网络均值/标准差仍每 2ms 重算，不是整条动作锁定 50ms，也不是做了 100ms/50ms 成功率对照。

固定 N2 动力学、2N 搜索力、5N/0.1N·m 保护以及原有恢复/加载旋转风险机制；没有因本次上传修改控制参数、锚点、奖励、熵或成功判据。

## 权重与结果边界

F4000 来自 2026-10-29 修复参考限制一致性后的 8 回合在线训练，共 4000 次更新。该轮同条件固定导纳与 SAC 确定性开发评价均为 0/4，未证明训练改善成功率。

之后的 2026-10-30 四次试验使用同一冻结 F4000，有随机探索但 **0 参数更新**。工况均含 X/Y 各 +0.30mm、roll −1°、pitch +1°，再配初始 yaw ±1.5° 与被动 yaw 开/关。没有只测单独 yaw。

原 1nm 自动口径为 0/4。负 yaw 开启支实际上达到目标深度并停稳，九针在主孔层有约 3.640～3.837mm 覆盖；仅两针数纳米接触重叠超旧几何容差。用户接受这种微小重叠后，该保存点按新口径为 1/4。通用几何数值容差于 2026-11-01 改为 10nm，其他成功条件和 100ms 连续保持不变，旧记录和权重未改写。

精简包明确携带的是 **旧判据下训练的权重 + 当前 10nm 源码**；不能把保存点重判写成训练收益，也不能把 1/4 当作已证明的重复成功率。尚无同条件证据证明 SAC 增益或 50ms 优于 2ms。完整 B.2/C 未验收，没有最终测试。科研累计初始化 443，本次上传新增初始化、物理步、神经推理和训练更新均为 0。

## 安装与核对

建议 Python 3.13 x64。`requirements-core-20261102.txt` 记录当前 Python 依赖版本；不上传虚拟环境或依赖包本体。历史实验使用的 MuJoCo 3.13.0 运行时有独立文件摘要，普通同版本安装包不自动等同于封存运行时，见 `configs/five_axis_current/runtime_source.json`。

```powershell
python -m pip install -r requirements-core-20261102.txt
python -B -m tools.publication.five_axis_policy
```

第二条仅检查发布权重和配置字节，不做神经推理、仿真或训练。需要在代码中显式读取模型时，可使用：

```python
from tools.publication.five_axis_policy import load_policy
policy = load_policy()  # 只构建并装入参数；后续观测/阶段门控由调用方负责。
```

最近实际模型的 include 与 mesh 路径已按发布目录静态核对；该模型用于说明真实几何/动力学配置。当前源码中旧封存批次入口依赖本地冻结来源、原回放、专用运行时和已有输出目录；精简包没有把这些档案伪造成完整复现实验环境，不应直接运行旧入口覆盖原批次。
