# D-sub 9 母头 V3 参数说明

## 本版修改

- 母头插座口的装配基准保持为 `Z = 0`。
- 薄底板前表面后移至 `Z = 4.10 mm`，底板厚度保持 `0.60 mm`。
- D形插座相对底板向公头方向凸出 `4.10 mm`。
- 公头V2的D形导向长度为 `4.00 mm`；完全插入时，导向末端与母头底板之间保留 `0.10 mm`轴向间隙。
- 底板后方保留 `5.00 mm`简化后壳，因此插座口至后壳末端总深度为 `9.70 mm`。
- 两侧空心固定柱随底板后移，向底板后方伸出 `3.50 mm`。

## 保持不变的功能尺寸（单位：mm）

| 项目 | 数值 |
|---|---:|
| 母孔直径 | Ø1.15 |
| 母孔深度 | 4.50 |
| 等效入口 | Ø1.35 × 深0.25 |
| 横向中心距 | 2.77 |
| 两排中心距 | 2.84 |
| 固定孔中心距 | 25.00 |
| 固定柱外径 | Ø5.00 |
| 固定柱中心孔 | Ø3.20 |

## 装配说明

- 固定母头，公头从负Z方向沿+Z接近。
- 母头插座口仍是装配定位基准，调整底板位置不会改变公母针孔对准关系。
- 公头V2无需修改，与本母头V3配套使用。
- 当前固定柱与母头主体合并为一个刚性实体，不包含真实螺纹、焊脚、内部簧片或材料弹性。
